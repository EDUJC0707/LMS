### 신규 기능
출결 관리(3.1.6, 단일 원천 SSOT) · 로그인 후 캘린더 홈(3.2.0) · 워크북 사진 업로드(3.1.7) · 약점체크 유사문항·문제은행 2종(3.1.8) · 상담 기록(3.1.9) · 성적표 개편/학습동선/테마별 정답률(3.2.1) · 게시판 확장(자유·이벤트/굿즈, 3.3.1)

### 5개 미결 해소 (2026-07-15)
1. **테마** = 신규 태그축(초기 중단원 복사 후 세분화)
2. **동보 수강료 없음** — 학원 과금은 커리큘럼(약 10주) 교재 1회 결제(결제선생)뿐 → `tuition_charges` 삭제
3. **질답 ↔ 문의** = 일단 통합(단일 창구, 추후 분리 여지)
4. **학부모 write** 허용(조회 + 결제·동보·상담 신청; 학습데이터·클리닉신청은 학생만)
5. **클리닉 평균 기준** = 전체평균 자동(A) 기본 + 컷값(B) 쉽게 교체

### 확정 기술 스택 (→ PRD 9장)
React SPA(Vercel/Cloudflare Pages) · Django + DRF · Fly.io(도쿄) · Celery + Redis(Upstash) · 오브젝트 스토리지(Tigris/R2) · Sentry · PostgreSQL

### 핵심 차별화 2가지 (홍보 포인트)
1. **결석생 직접 관리** — 당일 학부모 1차 전화 → 필요시 학생, 사유 파악 + 동보 안내 + 학습 대응 제안, 상담 LMS 기록
2. **시험 분석 + 약점체크 문항 제공** — 오답+추가마킹 문항 유사문항 자동 인쇄, 내신형/수능형 문제은행, 1년 수기 축적 후 AI 전환

## 회의 전사 (구조화, 자동전사 기반)

> 자동전사라 오탈자·동음이의 오인식 가능(예: "동보"=동영상 보강, "폴벳"=모노레포/폴더구조 추정). 전사본은 감사·근거 보존용.

### 로그인/권한
- 로그인 3종: 학생 / 학부모 / 관리자, 각각 다른 페이지.
- 학생·학부모 아이디·비밀번호는 연구실 일괄 생성 → 문자 발송 → 사용자가 비밀번호 변경.
- 자녀 둘 이상 학부모용 **드롭다운**으로 누구의 데이터인지 선택 조회.

### 영상 + 출결
- 출결을 엑셀에서 **LMS로 이관**. 담임이 성적처리하며 출석/결석/퇴원 표시.
- 출결은 학생·학부모에게 동일 노출(누적 확인).
- **출석생 = 그 주 복습영상 자동 지급**(신청/승인 없이). 현행 수기 권한부여 → 자동화.
- **동보(동영상 보강)**: 결석생 당일 전화상담 → "영상 받아 집에서 보겠다"=동보. 관리자 동보 체크 시 출석생과 동일 권한. 연락 안 되면 학생·학부모가 LMS에서 동보 신청.
- (정정: 회의에선 "동보=수강료 대상"이라 했으나, 이후 지섭 확인 결과 **동보 별도 수강료 없음** — 과금은 커리큘럼 교재 1회 결제뿐.)

### 클리닉
- 대상자 = 출석해서 현장 시험 응시 & 평균 미달. 시험 미응시자·결석생 제외.
- 관리자가 평균 입력 → 대상자만 활성화("신청"/"미대상자"). 시간대(월~금 슬롯) 버튼 신청·취소.

### 성적 처리 / 성적표 개편
- 아카플로우 성적표 불편 → 지섭이 새 포맷. 분석 자료·학습 방향 포함.
- 문항별 "틀렸을 때 학습할 것"(강의/개념서 페이지 등) 수기 입력 → 성적표 학습동선.
- AI 분석은 데이터 부족 → 1년 수기 축적 후 단계적 AI 전환.
- 누적 **테마별 정답률**(예: 중화반응 추이) 그래프화. 학생·학부모 열람.

### 약점체크 / 문제은행
- 틀린 문항 유사문항 2개 자동 조회→인쇄. **문제 DB 2종: 내신형(개념확인)/수능형**. 라벨링 툴에 내신/개념형 컬럼.
- 잘하는 학생용: OMR 추가 마킹란(더 풀고 싶은 문항 색칠) → 틀린 문항+마킹 문항 유사문항 제공.
- 성적처리 완료 시 학생별 PDF 자동 생성(1p 성적표 + 다시풀기 2단) → 인쇄만.

### 워크북(과제) 코멘트
- 조교가 워크북 마지막 페이지 수기 코멘트+ABC 도장 → 사진 업로드 → 학생 매핑. OCR 불필요, 관리용 원본 텍스트칸 1개.
- 학부모 문자 = 성적표 링크 + 과제 수행 여부(미수행/사진 링크).

### 게시판 / 캘린더 홈
- 게시판: 공지·질답·정오표 + 자유게시판(강사 트위터형) + 이벤트/굿즈.
- 로그인 후 첫 화면 = 통합 캘린더. 출결 도장·주차 커리큘럼·주 호버 시 Day 학습계획·오프라인 특이사항. UI 과복잡 지양.

### 교재 결제
- 결제선생. 학부모·학생 모두 결제 가능 + 중복 방지 sync. 주차별 아님, 커리큘럼(약 10주) 첫 수업 1회.

### 상담 / 결석 관리
- 결석 상담: 학부모 1차 → 필요시 학생(저녁 통화가능 시간). 상담 내용 LMS 기록. 학부모 상담 신청도 기록.

### 운영/인프라/일정
- 모니터링 대폭(AI 기반 버그 진단). 채널톡 등 상용 서비스(통화·문자) 연계 검토. 월 비용 산정.
- 예외 케이스 완벽 대응(현장 버그 대응 불가). 매일 전수 테스트.
- 지섭 백업으로 도훈 컴퍼니 파악. 서버 폴더 구조(모노레포?) 논의.

### 랜딩 페이지(비로그인)
- 잠재 고객 등록 전환 페이지(매우 중요). 고급·세련(토스 참고), 시즌 팝업("내 모의고사 넣으면 분석" 체험).
- 구성 후보: 게시판 항목/강사 사진/커리큘럼. UI 디자이너 협업 검토. 정보는 7월 마지막 주 확정, LMS 우선 개발.
