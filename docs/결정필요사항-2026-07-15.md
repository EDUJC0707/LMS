## 결정 1. 영상 호스팅 — DRM 호스팅 vs YouTube RPA

**보안 요건 확정(2026-07-17 수정, 대표)**: ① 다운로드 불가 **[필수]** ② **링크 노출 무력화 — 학생이 개발자 콘솔로 스트림 URL을 찾아내도 재생 불가 [절대 필수]**(= 짧은 만료 서명 URL로는 부족, 콘텐츠 자체 암호화 + 세션 귀속 라이선스 = **진짜 DRM**) ③ 워터마크+기록 추적 **[필수 아님 — 있으면 가점]**. 영상 원본 4K.
→ DRM 없는 서비스(Cloudflare Stream·api.video·YouTube 외 서명URL류)만 탈락. **워터마크 완화로 Mux·Bunny 후보 복귀** — 특히 4K에서는 분 과금인 **Mux(월 ~$119~122 고정)가 가격 우위**. 생존: **Mux / VdoCipher(워터마크 보너스) / Bunny+DRM / Kollus(견적)** — 하단 검토 문서 참조.

**선결 사실검증 완료(2026-07-17) — "50계정 한도"는 틀린 숫자. 실제는 더 나쁨(~32개, 비공식)**:
- "50"의 출처 = **2011년 공식 도움말**("up to 50 other users", [아카이브](http://web.archive.org/web/20110406145222/http://www.google.com/support/youtube/bin/answer.py?answer=157177)). **2013년경 문구 삭제** 후 [현행 공식 문서](https://support.google.com/youtube/answer/157177?hl=ko&co=GENIE.Platform%3DDesktop)에는 한도 언급이 없고, 블로그들이 15년째 재생산해온 숫자
- 실제 동작: **2025년 3월부터 사용자 검증 기준 약 32개에서 저장 차단** (피싱 악용 대응으로 축소된 것으로 추정, 공식 발표 없음. [커뮤니티 보고](https://support.google.com/youtube/thread/330304572?hl=ko) · [기사](https://techissuestoday.com/youtube-private-video-email-sharing-limit/)). 종전엔 300명 이상도 가능했다는 보고가 있어 **한도가 비공식·가변**
- **실무 검증법**: 테스트 영상에 이메일 33개 이상 추가 저장 시도(10분이면 확인). PRD 표기는 "50"이 아니라 "비공식 한도, 현재 관찰값 약 32, 가변"으로 수정 필요
- **판단 영향**: 반 인원이 32명을 넘으면 2안은 영상 사본 분할 운영이 강제됨 → 1안(DRM 호스팅)의 비용이 수용 가능하면 1안 쪽으로 기우는 재료

| | 1안: DRM 영상 호스팅 (VdoCipher / Mux) | 2안: YouTube 비공개 + RPA |
|---|---|---|
| 상태 | **비용 조사 완료** → [영상호스팅-검토](영상호스팅-검토-2026-07-17.md) | **테스트 완료** (`test/rpa-test/` — 부여·회수·재확인 실동작) |
| 비용 | **1080p·월 300h: VdoCipher 월 ~$58** (DRM·워터마크 포함) / 4K·대량: Mux 월 ~$110–122 | 호스팅 무료, 전용 PC 1대 |
| 링크 유출 방지 | DRM(Widevine/FairPlay)·서명 URL·워터마크 | 계정별 권한 (강함) |
| 임베드 | LMS 내 임베드 가능 (UX 우수, 유튜브 이탈 없음) | 불가 — 유튜브로 이동 + 계정 전환 필요 |
| 계정 한도 | 없음 | **약 32개(비공식·가변)** — 초과 시 사본 분할 필요 |
| 운영 리스크 | 월 비용 고정 발생 | Studio DOM 변경 시 봇 수리, 세션 만료 재로그인 |

**대안 전수조사 + Kollus 가격 확인 완료(2026-07-17)** — 글로벌 6종+국내 4종+AWS 조립식 비교 ([전수조사 표](영상호스팅-검토-2026-07-17.md) §4.5):
- **Kollus 탈락**: 아카이브 요금표(KOLLUS DRM ₩100만/월~)·리셀러 공개가(월 50만~100만원)·DART ARPU(월 ~140만원) 3경로 수렴 → **DRM 포함 월 ~100만원 + 1년 약정** — 이 규모엔 5~10배 과함
- **최종 후보 2 = 해상도 결정과 동일**: **4K 스트리밍 → Mux 월 ~$119~122 고정**(분 과금, 시청량 무관, 워터마크 없음) / **1080p 스트리밍 → VdoCipher 월 ~$58**(DRM+동적 워터마크 포함)
- 진행: 해상도 결정 → 해당 서비스 무료 체험으로 한국 회선 실측 → 확정. 해외 결제 공통 세금계산서 불가(+10%) 감안

## 결정 2. 클리닉 — 구글 미트 운영 방식

**방향**: 구글 미트 유지(PRD 6-3), **영상 녹화는 안 함**. 필요한 건 ① 감독용 **녹음(오디오)** ② **상담 요약** ③ LMS가 링크 자동 생성 → 시작 5분 전 학생에게만 노출.

**조사 완료(2026-07-17)** → 상세: [클리닉-구글미트-검토-2026-07-17.md](클리닉-구글미트-검토-2026-07-17.md)

- ✅ **녹화 없이 해결됨**: 전사(Transcripts) + Gemini "Take notes for me"(AI 요약)는 녹화와 **독립 기능**(녹화 OFF 가능), 둘 다 **한국어 지원**. 오디오만 녹음하는 네이티브 기능은 없으나 전사+요약이 공식 대체재 — 녹음 봇(월 ~7만 원대)·PC 캡처 우회 불필요
- ✅ **비용**: 조교(호스트)만 **Business Standard $14/월·인** 이면 됨(학생은 무료/무계정 참여) → 3~5석 월 $42~70. PRD 8-5(녹음 방식) 해소
- ✅ **API 자동화 전부 가능**: 링크 생성 → 회의별 **전사 ON·녹화 OFF 강제**(SpaceConfig) → 참가자별 입장/퇴장 시각(**클리닉 출결 자동 판정**, "10분 미입장 결석" 그대로 구현) → 전사 텍스트 API 수집(**30일 내 배치 필수**) → Gemini 요약 수집(2026-04 GA)
- ⚠️ **운영 필수**: 미트 링크는 회의 후에도 살아있어 재사용 시 이전 참석자 재입장 가능(구글 공식 경고) → **클리닉 1건 = 새 스페이스 1개** 생성. 입장은 `TRUSTED` 노크 → 조교 수락으로 통제
- **운영안(2026-07-17): 법인 계정 1개(Standard 1석, 월 $14)로 전 클리닉 주최** — 기능 자격이 주최자 기준이라 가능하고, 전사·요약이 한 Drive에 모여 수집도 단순, 조교 식별은 LMS 배정 기록으로 충분. **선결 테스트 1건**: 같은 계정으로 PC 2대에서 서로 다른 미트 동시 입장+전사 생성 확인(동시 슬롯 대비, 10분). 실패 시 동시 슬롯 수만큼 좌석 추가

## 결정 3. 상담·문의 옴니채널 = 채널톡 (전화 + 카톡·인스타·LMS 위젯, 2026-07-17 확대)

**방향(2026-07-17)**: 전화 관리뿐 아니라 **들어오는 문의 전부(카카오톡·인스타 DM·LMS 위젯)를 채널톡 인박스 하나로** 응대. 조사 결과 전부 지원 확인:
- ✅ **카카오톡 상담톡 연동** — 카톡으로 온 문의를 채널톡에서 답변(연동 무료, 답변 시 대화방당 80원/24h). 비즈니스 인증은 알림톡과 공통 전제
- ✅ **인스타그램 DM 연동** — 무료. 60일마다 재인증 필요(만료 시 수신 중단 — 운영 캘린더에 등록)
- ✅ 네이버 톡톡·LINE·이메일 등도 지원, **얼리 스테이지 플랜(월 27,000원)부터 전부 가능**
- 외부 채널 대화도 유저챗으로 기록 → 기존 웹훅+API 동기화 구조에 그대로 포함. 카톡 유입 고객↔기존 회원 프로필은 수동 통합(유니피케이션) 필요
- 효과: 전화·채팅·카톡·인스타가 **학생 1명 프로필 하나에 통합** + LMS 문의 기능 개발량 ~0. 공개 질답 게시판만 자체 개발 유지

**조사 완료(2026-07-15, 상세: [채널톡-도입검토](채널톡-도입검토-2026-07-15.md))**:
- ✅ 발신(070/기존번호 연동)·**자동 녹음 + STT + AI 통화 요약**(추가 비용 없음)·고객(학생)별 상담 이력 기록
- ✅ 전화 모니터링 대시보드(전화 수·응답률·부재중, 팀/기간 축)
- ⚠️ **"학생별 통화 횟수" 집계 리포트는 기본 미제공** → raw data 다운로드 가공 또는 Open API 추출로 해결 (도입 전 채널톡에 확인)
- 비용: 얼리 스테이지 플랜 월 27,000원(연결제) + 번호 5,000원/월 + 무선 발신 72원/분 → **월 5~6만 원대**
- 웹훅+Open API로 상담 이력을 LMS DB(`absence_counselings`)에 동기화 가능 → "기록 원본은 LMS" 유지

**남은 것**: 학생별 통화 집계 방식 1건만 채널톡에 확인 후 **도입 확정** 수준.

## 결정 4. 알림톡 자동화 — 수기 발송 제거

**문제**: 클리닉·영상·성적·결석 등 모든 알림이 현재 수기 발송. LMS 서버 이벤트(성적 등록 완료, 클리닉 배정, 출결 확정 등)가 나면 **자동으로 알림톡이 나가야** 함.

**조사 완료(2026-07-17)** — **"채널톡으로 되나?" → 되긴 되는데 최적이 아님. 전용 알림톡 API 권장.**

- **A. 채널톡**: 기술적으로 **가능** — 서버에서 이벤트 생성 API(`POST /open/v5/users/{userId}/events`, [문서](https://developers.channel.io/docs/create-an-event-1))로 이벤트를 쏘고, 캠페인이 그 이벤트를 트리거로 알림톡(7원/건) 자동 발송 가능(공식 지원). **그러나**: ① "이 유저에게 이 템플릿 즉시 발송" 직접 API가 없음(캠페인=마케팅 도구 경유 필수) ② 이벤트별 캠페인을 UI에서 하나씩 생성 ③ 발송 성공/실패를 서버에서 추적 어려움 ④ 캠페인 쿨다운이 하루 여러 번 발생하는 이벤트(성적 등록 등)와 충돌 위험 → **트랜잭셔널 용도로 부적합**
- **B. 전용 알림톡 API** ✅ **권장**: 직접 발송 API + 발송 결과 코드 회신 + SMS 대체발송(failover) 내장. 단가도 채널톡(7원)과 비슷하거나 더 저렴:
  - **솔라피(SOLAPI)**: 13원(월 1만건 미만)→8원(10만건)→최저 5.5원, 기본료 무료, **공식 Python SDK**(`pip install solapi`) ([단가](https://solapi.com/guides/tiered-pricing/))
  - **알리고(Aligo)**: **6.5원/건**, REST API + 템플릿 등록/검수 API ([알림톡 API](https://smartsms.aligo.in/alimapi.html))
  - NHN Cloud·비즈뿌리오: 견적 방식 `확인 필요`
- **공통 전제(어느 쪽이든)**: 카카오톡 채널 개설 → 비즈니스 채널 전환(사업자 인증) → 발신프로필 등록 → **템플릿 사전 검수**(정보성만 승인, 2~5영업일). 정보성 알림톡은 수신동의 불요·야간 제한 없음
- **확정 아키텍처 제안**: Django에 `NotificationService` 추상화(PRD 3.1.2의 채널 추상화 그대로) + Celery 비동기 큐 → **트랜잭셔널 알림톡 = 솔라피(실패 시 SMS 폴백)**, **채널톡 = 상담·전화(결정 3) 전용**으로 분리. 발송 이력·전달 상태(3.1.2 요구)가 LMS DB에 남음

## 그 외 남은 결정 (운영 세부 — 크지 않음)

자체개발 전제라 아키텍처급 결정은 위 4개가 전부. 나머지는 구현 중 확정 가능한 운영 규칙:

| 항목 (PRD) | 정할 것 | 언제까지 |
|---|---|---|
| **1차 오픈 범위·데드라인 (8-14)** | 범위 3~4배 확대로 8월 말 어려움 → 기능 컷 or 일정 재협의. **유일하게 큰 잔여 결정** | 착수 전 |
| 로그인 아이디 형식 (8-4) | "기억하기 쉬운 형태" 구체 규칙 + 중복 처리 — 계정 자동발급 배치의 선행조건 | 계정 기능 개발 전 |
| 퇴원·미등록 정의 (8-6) | 재등록 미완료 vs 1주차 미출석 | DB 확정 전 |
| 워크북 사진 매핑 (8-9) | 조교 수동 지정 vs 원번 인식 — 1차는 수동+검색 UI가 안전 | 해당 기능 개발 전 |
| 라벨링 툴 (3.1.8) | LMS 내장 vs 외부 도구 (모노레포 포함 여부) | 문제은행 개발 전 |
| 랜딩 페이지 구성 (6-10) | 게시판 공개 범위·강사 사진·커리큘럼 | **7월 마지막 주 (PRD 명시)** |

DB 설계 확정(모델 착수)은 결정이라기보다 위 항목들이 풀리면 따라오는 작업.
