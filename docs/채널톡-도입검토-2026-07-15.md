# 채널톡 도입 검토 (2026-07-15)

> **목적**: [결정필요사항 D5(문의 채널)](결정필요사항-2026-07-15.md) 및 PRD 9.2(결석 상담 통화·문자)의 채널톡 채택 판단 재료.
> **조사 방법**: 공식 출처(channel.io 가격 페이지·도움말·developers.channel.io) 우선 웹리서치, 2026-07 기준. 미검증 값은 `확인 필요`.
> **주의**: 채널톡은 **2025-11-28 가격제 개편** — 과거 MAU 과금이 아니라 현재는 **MU(연락처에 저장된 전체 고객 수) + 플랜** 구조. 구버전 블로그 정보와 혼동 금지.

---

## 0. 한 줄 결론 (TL;DR)

- **비용**: 이 학원 규모(고객 1,000명 이내, 상담원 2명)면 **얼리 스테이지 플랜 월 27,000원(연결제)** + 실비(전화번호 5,000원/월, 통화·문자·알림톡 건당)로 **월 5~7만 원대** 추정. 매우 저렴.
- **PRD 9.2의 핵심 질문 "통화 횟수 체크 되나?"** → **부분 충족**: 발신·자동 녹음·STT·AI 요약·고객별 이력 기록은 됨. 단 **"학생별 통화 횟수" 고객 축 집계 리포트는 기본 미제공** — raw data 다운로드 가공 또는 Open API 연동 필요.
- **"원본은 LMS DB" 원칙**: **충족 가능** — 웹훅(실시간) + Open API 폴링(보정)으로 상담·메시지 전문을 Django로 동기화 가능. 미납/해지 시 데이터 삭제 조항이 있어 동기화가 곧 백업이 됨(요건과 부합).
- **개인정보**: 주 인프라 **AWS 서울(국내)** + ISMS 인증. 수탁사(채널코퍼레이션) 고지 필요. **14세 미만 엔드유저(학생) 조항은 미확인** — 계약 전 직접 확인 필요.

## 1. 요금제 (2025-11-28 개편 후)

| 플랜 | 월 비용 | 포함 |
|---|---|---|
| 무료 | 0원 | 기본 채팅 + 미트(30명·1시간 제한). 최근 30일 상담만 조회 |
| **얼리 스테이지** | **연결제 27,000원 / 월결제 36,000원** | MU 1,000명, 기본 시트 5, **오퍼레이터 시트 2**. 상한: MU 3,000·기본 시트 10·오퍼레이터 5 |
| 그로스 | 연결제 90,000원 / 월결제 120,000원 | MU 3,000명 포함. 고객 ALF(AI 상담, 참여당 500원)는 그로스 이상 전용 |
| 엔터프라이즈 | 문의 | 연 매출 100억↑ 기업은 필수 |

- **MU 초과 과금**: 1~1,000명 구간 30원/명·월 (예: 고객 1,500명이면 +15,000원/월), 이후 구간 체감.
- **시트 추가**: 기본 시트 3,000원/월, **오퍼레이터 시트(채팅/전화 상담 담당) 60,000원/월** ← 상담원 3명째부터 최대 비용 요인.
- **우리 규모 추정(학생+학부모 MU ≤1,000, 상담원 2)**: 기본 포함으로 충족 → **플랜비 월 27,000원**.
- `확인 필요`: 얼리 스테이지 가입 자격 요건 명문화 여부, 그로스의 오퍼레이터 기본 시트 수(1로 표기 — 얼리보다 적어 재확인).

## 2. 전화(미트) — 결석 상담용 (PRD 3.1.9 / 9.2)

- **발신·수신**: PC·모바일 앱에서 인터넷전화. 070 번호 비대면 발급 또는 **기존 학원 번호 연동**, IP폰(유선 전화기) 연결 지원. ([미트](https://channel.io/kr/meet/call) · [번호 연동](https://docs.channel.io/help/ko/articles/%EB%B2%88%ED%98%B8-%EC%97%B0%EB%8F%99-fb35c768))
- **녹음·기록**: 통화 **자동 녹음 + STT(텍스트 변환) + AI 통화 요약이 추가 비용 없이** 제공. 통화가 고객별 상담(유저챗)으로 기록되어 검색·팀 공유 가능. ([사용 방법](https://docs.channel.io/help/ko/articles/%EC%82%AC%EC%9A%A9-%EB%B0%A9%EB%B2%95-28817485))
- **집계**: "전화 모니터링" 대시보드 — 전화 수·응답률·평균 통화시간·시간대 유입·부재중 유형(실시간+누적). 상담 통계 raw data에 인바운드/아웃바운드/부재중 구분 포함. ([전화 모니터링](https://docs.channel.io/help/ko/articles/%EC%A0%84%ED%99%94-%EB%AA%A8%EB%8B%88%ED%84%B0%EB%A7%81-92e1ba1c))
- **⚠️ 한계**: 집계 축이 팀/기간/상담원 중심. **학생(고객)별 통화 횟수 리포트는 기본 미제공** → raw data 가공 or Open API 추출 필요. `확인 필요`(실사용 검증 권장)
- **과금(실비)**: 유료 플랜 필수. 번호 **월 5,000원(얼리)/9,000원(그로스)**, 발신 **유선 15원/분·무선(010) 72원/분**, 수신 무료. ([사전 준비](https://docs.channel.io/help/ko/articles/%EC%82%AC%EC%A0%84-%EC%A4%80%EB%B9%84-ebe39da2))
- 예시: 월 결석상담 발신 100통×3분(무선) ≈ 21,600원.

## 3. 문자·알림톡 (PRD 3.1.2 알림 채널과 연계)

- **SMS 10원 / LMS 28원**(선불 충전, 길이 자동 전환). 발신번호 사전등록 필수. 마케팅 문자는 비즈니스 인증+수신동의+08~20시 제한. ([문자](https://docs.channel.io/help/ko/articles/%EB%AC%B8%EC%9E%90-ba987cea))
- **카카오 알림톡 7원/건** — 정보성만 가능. 레시피(사전 검수) 템플릿 즉시 사용, 개인 템플릿은 카카오 검수 2~3영업일. ([알림톡](https://docs.channel.io/help/ko/articles/%EC%95%8C%EB%A6%BC%ED%86%A1-9747de9a)) 친구톡(광고성)은 문서상 언급 없음 → `확인 필요`(미지원으로 보임)
- **자동 발송**: "캠페인"으로 이벤트 트리거 → 대기/분기 → 메시지·문자·알림톡 발송, **알림톡 실패 시 문자 대체 발송** 흐름 구성 가능. ([캠페인](https://docs.channel.io/help/ko/articles/9064c609)) 워크플로우 월 50건·마케팅 메시지 월 30건 무료 후 건당 과금.
- **⚠️ 기술 검증 포인트**: 트리거용 커스텀 이벤트(예: "결석 발생") 주입이 SDK(track) 기준으로 문서화됨 — **서버(Django→Open API)에서 이벤트 생성 가능 여부 `확인 필요`**. ([이벤트](https://developers.channel.io/reference/event-kr))
- 참고: PRD 3.1.2의 알림 채널 추상화 원칙과 부합 — 채널톡을 "알림 채널" 구현체 중 하나로 두면 교체 가능.

## 4. LMS 연동 (Open API·웹훅·위젯)

- **상담 이력 export**: `GET /open/v5/user-chats`(목록) + `GET /open/v5/user-chats/{id}/messages`(전문) — limit 500·`since` 커서로 전량 순회 가능. 인증은 Access Key/Secret 헤더. Rate limit 토큰버킷(용량 100, 10tps) → 야간 배치 전량 동기화 무리 없음. ([UserChats](https://developers.channel.io/en/articles/List-of-UserChats-a7e8e5d1) · [Messages](https://developers.channel.io/en/articles/Get-a-UserChats-messages-738ccde7) · [Rate Limiting](https://developers.channel.io/docs/rate-limiting))
- **웹훅**: Message/UserChat/User 이벤트를 Django로 push 수신(`userChatOpened` 등 scope 구독, `token`으로 검증). "상담 종료" 전용 이벤트 보장 여부 `확인 필요` → **웹훅(실시간) + API 폴링(보정) 병행** 설계가 안전. ([Webhook events](https://developers.channel.io/en/articles/Webhook-events-7bd9b8e2))
- **React 위젯**: 공식 SPA 패턴(`loadScript`/`boot`/`shutdown`). 로그인 연동은 `memberId` + **`memberHash`(서버 HMAC-SHA256 서명 — 사칭 방지, 공식 권장)** + `profile` 커스텀 필드(학생ID 등). 모바일은 전체화면 메신저로 전환되는 반응형. ([Web Quickstart](https://developers.channel.io/docs/web-quickstart) · [Member Hash](https://developers.channel.io/en/articles/cca4bd14) · [Boot Option](https://developers.channel.io/docs/web-boot-option))
- **UI 대량 다운로드**: 상담 1만 건/고객 3만 건 per 회. ([데이터 다운로드](https://guide-kr.channel.io/d6913f5f-6fac-49a0-a334-ae8863dbb4f4))

## 5. 개인정보 (D2와 연계)

- **위탁 구조**: 약관상 사업자(학원)가 채널코퍼레이션에 개인정보 처리업무를 **위탁** → **LMS 개인정보처리방침에 수탁사 고지 필요**. 데이터의 법적 책임은 학원 측에 귀속. ([이용약관](https://channel.io/ko/terms))
- **보관 위치**: 주 인프라 **AWS 서울 리전(국내)**, ISMS 인증 보유. 단 AI 기능(OpenAI 등/미국, ZDR 명시)·SMS(Twilio)·분석(Mixpanel/GA) 등 부가기능은 **국외 이전 수반** → 켜는 기능에 따라 처리방침에 국외이전 항목 반영. ([개인정보 처리방침](https://channel.io/ko/privacy))
- **⚠️ 14세 미만**: 채널톡 계정(팀 멤버) 가입은 14세 미만 불허 조항만 확인됨. **위젯 엔드유저(학생)가 14세 미만인 경우의 조항은 미확인** — 중1(만 12~13세) 학생이 있을 수 있으므로 법정대리인 동의 의무는 학원 책임으로 보고 **계약 전 채널톡에 직접 확인** `확인 필요`
- **보존·삭제**: 해지 시(그리고 **미납 시에도**) 법정 보유분 제외 일체 삭제 조항 있음. 해지 시 export 유예 기간 명시 없음 `확인 필요` → **상시 동기화 파이프라인이 곧 백업**(§4)이므로 원칙과 부합.

## 7. 계약 전 채널톡에 직접 확인할 것 (미해결 6건)

1. **학생(고객)별 통화 횟수 집계** — 대시보드/커스텀 리포트로 가능한지, raw data·API 가공이 유일한지
2. **14세 미만 엔드유저** 관련 계약 조건·법정대리인 동의 처리
3. **상담 종료(closed) 웹훅 이벤트** 지원 범위
4. **서버(Open API)에서 캠페인 트리거용 이벤트 생성** 가능 여부
5. **해지 시 데이터 export 유예 기간**
6. 친구톡(광고성 카카오 메시지) 지원 여부

## 8. 판단 (D5 선택지에 대한 시사점)

- **C안(채널톡=상담 운영 전화·문자, 문의는 자체)**: 조사 결과 **가장 무리 없음** — 전화 녹음·이력·문자·알림톡은 검증됨, 유일한 갭(학생별 횟수 집계)은 API 가공으로 해결 가능.
- **B안(1:1 문의도 채널톡 위젯)**: 기술적으로 전부 가능(memberHash 연동 + 웹훅/API 동기화). 8월 데드라인(D4) 압박 시 문의 개발량을 크게 줄여줌. 갭: 14세 미만 조항 확인 필요, 질답 게시판은 어차피 자체 구축.
