## 소비자 경험 개선 과제 (2026-07-14 논의)

**배경**: 현재 PRD는 공급자(관리자·조교) 수작업 제거 중심으로 작성됨. 소비자(**학생 + 학부모 모두**)는 대부분 정보를 받기만 하는 수동적 수신자로 등장. 아래는 소비자 관점에서 보강이 필요한 항목.

**핵심 관점**: 지금은 학생이 성적표를 종이로 받고 클리닉·영상 만료·교재 구매를 **현장 구두 안내**로만 챙김 → 사이트에 로그인할 이유 자체가 없음. 소비자(학생·학부모)가 "여기 들어오면 내가 챙길 걸 알려준다"고 느끼게 만드는 것이 목표.

### 우선순위

| 순위 | 항목 | 대상 | 상태 |
|---|---|---|---|
| 1 | 학생 홈(대시보드) 신설 | 학생 | 대기 |
| 2 | 성적표 → 학습 동선 연결 / 영상 만료 사전알림·연장 | 학생 | 대기 |
| 3 | 학부모 뷰(자녀 성적·출결·결제 조회) / 결제 상태 소비자 노출 | 학부모 | 대기 |
| 4 | 클리닉 취소·노쇼 경고 투명화 / 온보딩·모바일 / 문의 알림 | 학생·학부모 | 대기 |

### 1. 학생 홈 / 통합 대시보드 (최우선)

- **As-is**: 로그인 후 무엇을 보는지 정의 없음. 클리닉 입장·복습영상 만료·구매 필요 교재 등을 학생이 **현장 구두 안내·기억에 의존**해 각자 챙김. 놓치면 본인 손해. 사이트에 로그인할 이유가 없음.
- **To-be**: 로그인 직후 **"오늘 내가 놓치면 안 되는 것"** 대시보드. 구두로 하던 안내를 카드로 매핑:
  - 오늘의 클리닉(시작 5분 전 링크 활성) → 입장하기
  - 만료 임박 복습영상(D-2 등) → 시청 / 연장신청
  - 구매 필요 교재(신규생은 구매창이 짧음) → 구매(청구)
  - 새 성적표 도착 → 성적표 보기
  - 미확인 공지 · 문의 답변 → 확인
- **원칙**: 마감이 있는 것(클리닉 시간, 영상 만료, 결제 기한)을 상단에 배치.
- **배치 제안**: PRD 3.2에 "3.2.0 학생 홈(대시보드)"로 성적표(3.2.1)보다 앞에 신설.

### 2. 복습영상 시청 경험 (학생)

- **As-is**: 비공개 유튜브라 LMS 임베드 불가 → 유튜브로 이탈, 본인 구글 계정 로그인 전환 필요(모바일 계정 다중 시 불편). 만료 시 페이지 "자동 소멸"만 됨.
- **To-be**:
  - 시청 전 "어느 구글 계정으로 봐야 하는지" 안내 + 계정 전환 가이드
  - 만료 N일 전 사전 알림 + 재신청(연장) 버튼
  - 50개 공유 한도(8-2)로 신청 막힐 때 소비자에게 보이는 대기열/순번 안내

### 3. 성적표를 "결과 통보"에서 "학습 동선"으로 (학생)

- **As-is**: 3.2.1 성적표는 점수·백분위·단원별 정답률의 정보 나열. 취약 단원을 알아도 다음 행동은 학생 몫.
- **To-be**:
  - 회차별 추이 그래프 시각화
  - 취약 대단원 → 해당 복습영상/클리닉 신청 버튼 연결
  - 지난 회차 대비 오른/떨어진 단원 하이라이트

### 4. 학부모를 소비자로 정식 대우 (학부모)

- **As-is**: 6-2에서 학부모 전용 계정은 1차 범위 밖. 학부모는 알림톡·청구서를 받기만 하고 직접 조회 불가. 실제 결제 의사결정자인데 접근권이 없음.
- **To-be**:
  - 최소 읽기 전용 학부모 뷰(자녀 성적/출결/결제 상태 조회)라도 1차 검토
  - 전용 계정이 부담이면 알림톡에 개인화 조회 링크(토큰 기반)라도 포함
  - 데이터 모델은 이미 확장 대비(6-2) → UI만 얹으면 됨
- **미결**: 학부모 전용 계정을 1차 범위에 넣을지 여부 (6-2 재검토 필요).

### 5. 결제 상태 소비자 노출 (학생·학부모)

- **As-is**: 결제 상태(완료/미결제/배부)는 관리자만 조회(3.1.5). 학생·학부모는 "결제됐나? 교재 언제 받나?"를 알 수 없음.
- **To-be**: 소비자 화면에도 내 결제/배부 상태 표시("결제완료 · 배부대기"). 미결제 청구는 대시보드에서 재확인·재발송 요청.

### 6. 클리닉: 신청자 관점의 투명성·통제권 (학생·학부모)

- **As-is**: 신청·시간수정은 되나 취소 기능 명시 없음. 노쇼 2회 → 영구 제한(수동 해제)이 소비자에게 불투명. 시작 리마인더 없음(링크만 5분 전 노출). 승인·배정 결과는 학생이 직접 조회해야 함.
- **To-be**:
  - 취소 버튼(마감 규칙 내) — 취소는 노쇼로 안 잡히게
  - 노쇼 1회 시 사전 경고 + 남은 횟수 표시("1회 더 시 제한")
  - 클리닉 시작 전 리마인더 알림(학생 본인)
  - 승인/배정 결과 push 알림(현재는 조회 방식)

### 7. 온보딩 & 접근성 (학생)

- **As-is**: 신규생 계정 자동발급·랜덤 비밀번호(3.1.5)이나 첫 로그인 경험 미설계. 미등록생은 교재 구매만 가능한데 왜 나머지가 잠겼는지 안내 없음. 모바일 최적화 언급 전무.
- **To-be**:
  - 첫 로그인 시 비밀번호 변경 + 구글 시청계정 등록 온보딩 플로우
  - 미등록 상태 잠긴 기능에 "1주차 출석 후 열립니다" 안내 배지
  - 모바일 우선 반응형을 비기능 요구사항(4장)에 명시 (8-3 휴대폰 미사용 학생 접근성과 연결)

### 8. 문의 응답 경험 (학생)

- **As-is**: 3.3.2 LMS 자체 채팅/게시판으로 등록·답변. 학생이 답변 왔는지 알 방법·기대 응답시간 없음.
- **To-be**: 답변 등록 시 학생 알림 + 대시보드 "안 읽은 답변" 표시. 상태(접수/처리중/완료) 표기.

### 9. 소비자 측 성공지표 보강 (5장 관련)

- **As-is**: 5장 성공지표가 전부 공급자 측(수작업 시간 단축, 자동화율). 소비자 성공을 측정할 지표 없음.
- **To-be**: 학생 주간 로그인율·재방문율, 대시보드 알림 → 행동 전환율(시청/입장/결제), 클리닉 노쇼율·교재 결제 누락률 감소.
