회의 이후 반영

시스템별 변경 사항

성적 처리 · 리포트

  • 반 이동 시에도 원번+이름 대조로 성적표 오배정·누락 방지 (학급은 매칭 키 아님)
  • 미응시 출석생 — 성적표 미생성 후 '성적표 없음' 표기, 시험 0점(미응시), 과제는 수동 입력, 리포트는 발송

복습영상

  • 유튜브 권한 승인을 별도 PC의 AI 봇(RPA)으로 자동화할 예정
  • 봇 자동화가 제한되면 외부(전용) 영상 서버로 전환 가능성 명시

계정 · 권한

  • 신규생 계정 자동 발급 — 출석일 1일 전 / 아이디는 기억하기 쉬운 형태 / 비밀번호 랜덤·변경 가능
  • 원번 고정(불변) — 전화번호가 바뀌어도 유지
  • 미출석 학생 = 교재 구매만 개방
  • RBAC 도입 — 대표·관리자·조교·출석·미출석 / 출석은 관리자가 DB 입력

클리닉

  • 출결 알림 진행 중 발송(종료 후 아님)
  • 출석 = 조교가 정상 진행 가능 확인 후 버튼 → 누른 순간 알림(지각 포함) / 결석 = 시작 +10분 버튼
  • 녹화 제거 → 녹음만(조교 감독) + 평가표 기반 수행 평가
  • 신청 시간 수정 가능 / 당일 오전 8시 마감
  • 노쇼 누적 2회 → 영구 제한(관리자 수동 해제) + 경고 알림

랜딩 페이지

  • 로그인 이전 한종철 강사 소개 랜딩 페이지 추가 예정 (구성은 추후 논의)
