시스템 3 · 결제

교재 결제

학생 버튼 한 번으로 학부모에게 청구서가 나가고, 결제 상태는 관리자 화면에서 바로 확인합니다.

As-is현재 방식
1

학원으로부터 등록생 명단·학부모 연락처를 수령

2

카카오톡으로 청구서(결제선생)를 등록생마다 사람이 일일이 개별 발행

3

결제내역을 확인한 뒤 교재 배부 — 여러 외부 프로그램과 확인 단계를 거쳐 시간이 오래 소요

To-be개선 방식
1

결제선생을 LMS에 임베드

2

학생이 교재 구매 버튼 클릭

3

LMS가 학생 계정에 등록된 학부모 연락처로 청구서 자동 발송

4

결제 확인 시 관리자 페이지에서 상태(결제 완료·미결제·배부 여부) 조회

개선 효과

  • 청구 자동화 — 등록생별 개별 수동 발송을 제거합니다.
  • 단계 단축 — 결제 확인까지 거치는 사람과 소요 시간을 줄입니다.
  • 사용성 향상 — 학부모는 LMS 단일 흐름에서 결제합니다.
  • 상태 가시화 — 학생별 결제·배부 현황을 한 화면에서 일괄 확인합니다.

참고1차는 결제선생을 그대로 유지·임베드하고, 추후 PG(결제대행) 직접 연동으로 전환할 수 있도록 설계합니다.

결제 로직을 Provider 인터페이스로 추상화해, PG 직접 연동으로 바꿔도 주변 기능은 변경하지 않습니다.
