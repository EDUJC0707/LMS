시스템 2 · 영상

복습영상 · 결석보강 수강

카카오톡·엑셀로 흩어진 영상 신청과 권한 관리를 LMS 한 곳에서 처리하고, 유출 방지 수준은 그대로 유지합니다.

As-is현재 방식
1

카카오톡으로 개별 신청을 접수하고 신청자의 구글 이메일을 수령

2

비공개 유튜브 영상을 해당 계정에만 사람이 수동으로 공개 전환

3

부여 내역을 엑셀에 수기로 정리 — 누락·지연 위험

4

일주일 후 계정을 다시 찾아 비공개로 전환(전 과정 수동)

To-be개선 방식
1

학생이 LMS에서 신청(시청용 구글 계정 포함)

2

LMS가 자동으로 자격 확인하거나 관리자가 승인

3

관리자가 유튜브에서 권한 부여 — LMS가 대상·계정·기한을 할일 목록으로 제시

4

학생에게 알림으로 안내

5

학생이 LMS 시청 링크로 접속해 본인 구글 계정으로 유튜브에서 시청

6

1주 후 LMS 시청 링크 자동 소멸, 관리자에게 “유튜브 권한 삭제 필요” 리마인더

개선 효과

  • 자동화 — 신청·이력·만료 리마인더를 자동화해 관리자 수작업과 누락을 줄입니다.
  • 카톡 제거 — 개별 카카오톡 접수 없이 LMS 단일 창구에서 신청을 받습니다.
  • 유출 방지 유지 — 비공개·계정별 권한으로 링크가 유출돼도 타인 시청을 차단합니다.
  • 이력 추적 — 부여 계정·부여일·만료 예정일·삭제 여부를 LMS가 자동 기록해 엑셀을 대체합니다.
  • 일원화 — 복습영상과 결석보강을 하나의 플로우로 통합하고 유형만 구분합니다.

참고비공개 영상은 LMS에 임베드할 수 없어 시청은 유튜브에서 이루어집니다(외부 이동).

유튜브 계정 권한의 부여·삭제는 API 자동화가 불가해 관리자가 직접 처리하며, LMS는 할일·알림·이력으로 보조합니다.

비공개 영상은 영상당 공유 계정이 최대 50개로 제한되어, 대량 신청 영상은 별도 운영 방안이 필요합니다.
