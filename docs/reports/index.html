분산된 학원 운영을 하나의 LMS로

현재 성적 처리, 복습영상 제공, 교재 결제, 학생 상담이 아카플로우·YouTube·결제선생·카카오톡에 나뉘어 운영되고 있습니다. 본 보고는 이 분산된 기능을 하나의 LMS로 일원화하여 관리자의 반복 수작업을 줄이고 학생에게 단일 진입점을 제공하려는 개선 방향을 정리한 것입니다.

배경

성적, 복습영상, 교재 결제, 상담 기능이 각기 다른 외부 서비스에 흩어져 있습니다. 관리자는 여러 시스템을 오가며 명단 대조와 자료 배부, 결제 확인 등 같은 업무를 수작업으로 반복하고, 학생은 기능마다 진입점이 나뉘어 있습니다.

목적

분산된 기능을 하나의 LMS로 일원화합니다. 관리자의 반복 수작업을 줄이고, 학생에게는 모든 기능을 하나의 진입점에서 이용하도록 하여 외부 서비스 의존을 낮추는 것을 목표로 합니다.

시스템별 As-is → To-be

시스템 1성적 처리 및 성적표 배부OMR 자동 채점과 표준 성적표를 LMS에서 산출·조회보기 시스템 2복습영상 · 결석보강 수강신청·권한·만료를 LMS에서 관리보기 시스템 3교재 결제버튼 한 번으로 학부모에게 청구·결제 연결보기 시스템 4클리닉(1:1 화상 과외)신청·배정·입장을 LMS에서 통제보기 시스템 5문의 · 게시판카카오톡 개별 응대를 자체 채팅·게시판으로 정리보기

공통 축

  • 단일 진입점 — 흩어진 기능을 하나의 LMS로
  • 알림 채널 추상화 — 현재 카카오 알림톡, 향후 자체 앱 푸시 등으로 확장·교체
  • 교체 대비 모듈화 — 결제(결제선생→PG)·화상(구글 미트)·영상 모듈을 인터페이스로 추상화
