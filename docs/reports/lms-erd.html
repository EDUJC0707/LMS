표(테이블)들이 어떻게 연결되는지 한눈에 보는 그림입니다. 화살표 = "이 표가 저 표를 가리킨다(외래키 FK)", 화살표 위 글자 = 연결의 의미. 같은 색 상자 = 같은 도메인.

파란 상자 = 두 중심 허브 (users·students) ─► 실선 = 반드시 가리킴 ┈► 점선 = 셋 중 하나만 가리킴(대상 택1) 1:1 / 1:N = 한 개 : 여러 개 관계
