> **목적**: [결정필요사항 §결정 2](결정필요사항-2026-07-15.md)의 판단 재료. PRD 6-3(구글 미트 유지)·8-5(녹음 방식)의 답.
> **전제**: 1:1 클리닉, **영상 녹화 안 함**, 감독용 녹음(오디오)+상담 요약 필요, LMS가 링크 자동 생성·시작 5분 전 노출.

## 0. 한 줄 결론 (TL;DR)

**Business Standard 좌석(조교당 $14/월, 연 약정)만 있으면 "녹화 없이 전사+AI 요약"이 공식 기능으로 해결되고, 링크 생성→설정 강제→출결 기록→전사·요약 수집까지 전부 API로 자동화 가능.** 녹음 봇·PC 캡처 같은 우회는 불필요. 학생은 무료(무계정도 가능, 노크 입장).

- **오디오만 녹음하는 네이티브 기능은 없음** → 공식 대체재 = **전사(Transcripts) + Gemini "Take notes for me"(AI 요약)**. 둘 다 **녹화와 독립**(녹화 OFF 가능)이고 **한국어 지원**.
- 감독 목적상 "녹음 파일" 자체가 꼭 필요하면 녹음 봇(월 ~7만 원대)이 대안이지만, 전사 텍스트+AI 요약으로 충분하면 추가 비용 0.

## 1. 에디션·가격 (Workspace, 연 약정 USD)

| | Starter $7 | **Standard $14** | Plus $22 |
|---|---|---|---|
| 녹화 | ✗ | ✓ | ✓ |
| 전사(Transcripts) | ✗ | ✓ | ✓ |
| Gemini 노트(Take notes for me) | ✗ | ✓ | ✓ |
| 자동 아티팩트 설정·출석 리포트 | ✗ | ✗ | ✓ |

- **필요 기능 3종의 최저 에디션 = Business Standard.** ([녹화](https://support.google.com/meet/answer/9308681) · [전사](https://support.google.com/meet/answer/12849897) · [Gemini 노트](https://support.google.com/meet/answer/14754931))
- **좌석은 호스트(조교)만 유료면 됨** — 기능 자격은 주최자 에디션 기준, 학생은 무료 계정/무계정 참여 가능. 조교 3석 $42/월 · 5석 $70/월 (~6~10만 원, 환산 추정). 신규 가입 프로모션(12개월 10%) 있음.
- 전사·Gemini 노트 **한국어 공식 지원** (영·불·독·이·일·한·포·스).
- `확인 필요`: 한국 직접 결제는 USD 청구로 보임(공식 KRW 정가 부재) — 원화 청구 원하면 국내 리셀러(GoWid·메가존 등) 경유.

## 2. "녹화 없이 녹음+요약" 달성 방안 비교

| | **A. Meet 전사 + Gemini 노트 (권장)** | B. 녹음 봇 (Recall.ai/Attendee/Vexa) | C. 조교 PC 오디오 캡처 + STT |
|---|---|---|---|
| 산출물 | 발화 단위 전사 텍스트 + AI 요약 Docs | 오디오 파일(MP3) + 전사 | 오디오 파일 + 전사 |
| 자동화 | **API로 회의별 강제 설정 가능**(전사 ON·녹화 OFF) | 봇이 참가자로 입장 — **매번 호스트 수락 필요**, 화면에 보임 | 수동 시작/업로드 → 누락 위험. 자동화하려면 크롬 확장 자체 개발 |
| 추가 비용 | **0** (Standard 좌석에 포함) | 시간당 ~$0.50 → 월 100시간 ~$50–65 (7~9만 원) | STT ~$0.18~0.36/시간 (월 100시간 2~4만 원) + 개발비 |
| 리스크 | 전사 엔트리 API 보존 **30일**(Docs 파일은 Drive에 영구) → 30일 내 LMS 수집 배치 필수 | 외부 서비스 의존, 한국어 STT 품질 `확인 필요` | 신뢰성 최악(사람 의존) |

**권고**: A안. 조교 수행 감독은 전사 텍스트+AI 요약으로 충분하고, LMS가 회의 종료 후 전사를 수집해 `clinic_evaluations`(녹음경로·AI요약 컬럼 이미 있음)에 저장하면 평가표 워크플로우(3.2.4)와 그대로 연결됨.

## 3. API 자동화 범위 (Meet REST API v2 + Calendar API)

LMS(Django)에서 서비스계정 + **도메인 전체 위임(DWD)** 으로 조교 계정을 impersonate하는 것이 공식 서버측 패턴. ([인증 가이드](https://developers.google.com/workspace/meet/api/guides/authenticate-authorize))

| 하는 일 | 방법 | 근거 |
|---|---|---|
| 미트 링크 생성 | Calendar `events.insert`(+`conferenceData.createRequest`) 또는 Meet `spaces.create` | [spaces.create](https://developers.google.com/workspace/meet/api/reference/rest/v2/spaces/create) |
| **회의별 전사 ON·녹화 OFF 강제** | `SpaceConfig.artifactConfig`의 `transcriptionConfig=ON`, `recordingConfig=OFF` (2025-04 GA) | [spaces 설정](https://developers.google.com/workspace/meet/api/guides/meeting-spaces-configuration) |
| 입장 통제 | `accessType=TRUSTED/RESTRICTED` → 링크만 가진 학생은 **노크 → 조교 수락**. 무계정 학생도 노크 가능 | [spaces](https://developers.google.com/workspace/meet/api/reference/rest/v2/spaces) |
| **클리닉 출결 판정** | `conferenceRecords.participants.participantSessions` — 참가자별 입장/퇴장 시각 → "10분 미입장 결석 처리"(3.2.4) 자동 판정 근거 | [participantSessions](https://developers.google.com/workspace/meet/api/reference/rest/v2/conferenceRecords.participants.participantSessions) |
| 전사 수집 | `conferenceRecords.transcripts.entries` — 발화 단위 텍스트 직접 조회(Docs 안 거침). **종료 후 30일만 보존** → 배치 수집 | [artifacts 가이드](https://developers.google.com/workspace/meet/api/guides/artifacts) |
| AI 요약 수집 | `conferenceRecords.smartNotes` (2026-04 GA) → Docs 파일 → Drive API로 내용 취득 | [릴리스 노트](https://developers.google.com/workspace/meet/release-notes) |

`확인 필요`: Calendar로 만든 회의의 스페이스에 `spaces.patch`로 artifactConfig 적용되는지(모델상 되는 것으로 보이나 e2e 미확인 — 테넌트에서 테스트 1회 권장) · 무계정 학생의 이름 기록은 자기신고 `displayName`뿐이라 출결 매칭은 "슬롯당 1명" 전제로 처리.

## 4. 운영 주의 — 링크 재사용 리스크

- **미트 링크는 회의가 끝나도 죽지 않음**(수 주~수개월 유효). 재사용하면 이전 참석자가 재입장할 수 있다고 **구글이 공식 경고** ([문서](https://support.google.com/calendar/answer/16876004)). `endActiveConference` API도 링크를 무효화하지 않음.
- → **클리닉 1건마다 새 스페이스 생성**이 필수. "시작 5분 전 학생에게만 노출"(PRD 3.2.4)은 LMS 화면 노출 제어 + 노크 수락으로 이중 통제.

## 5. PRD 반영 포인트

- **8-5(녹음 방식) 해소안**: "미트 전사 + Gemini 노트(녹화 OFF)"로 확정 제안 — 별도 녹음 장치·봇 불요
- 6-3 체크리스트 중 "미트 링크 생성 자동화" → Calendar/Meet API 자동 생성으로 확정 가능
- 3.2.4 "10분 미출석 결석 처리" → participantSessions 기반 자동 판정 + 조교 수동 버튼 병행
- 비용: Workspace Business Standard 조교 3~5석 = **월 $42~70** (클리닉 운영의 유일한 고정비)
