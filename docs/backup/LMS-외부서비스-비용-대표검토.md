## 영상 호스팅

### 요건
- 다운로드 불가
- 콘솔로 링크 찾아도 재생 불가 (**DRM**)
- 워터마크 (가점)
- 4K 원본 / LMS(웹·앱) 임베드

> **DRM이란?** 영상 자체를 암호화하는 기술. 학생이 개발자도구·콘솔로 영상 주소를 빼내도 파일이 암호화돼 있어 재생 불가. 복호화 열쇠는 "로그인한 그 학생·그 기기"에만 잠깐 발급 → 링크 유출·다운로드·크롤링 도구 전부 무력화. (단순 링크 숨김/유튜브 계정 공유와 근본적으로 다름)

### 1안 — DRM 호스팅 (VdoCipher / Mux)
| | VdoCipher | Mux |
|---|---|---|
| DRM | ✅ 기본 | ✅ ($100/월) |
| 동적 워터마크 | ✅ 기본 | ❌ (정적만) |
| LMS 임베드 | ✅ | ✅ |

| 비용 | 4K | 1080p |
|---|---|---|
| VdoCipher | $163 (월 300h) ~ $503 (1,000h) | $58 (300h) |
| Mux | ~$120 고정 | ~$110 |

### 2안 — YouTube (무료)
- RPA 테스트 완료 (부여·회수 실동작)
- 32개 한도 → 초과 시 영상 사본 분할
- 코드 변경 시 공유 중단 (복구 ~1일)
- **LMS 임베드 불가** (유튜브 이동 + 본인 구글 로그인)

### 비용 구조
- **VdoCipher**: 연간 선불. 대역폭(GB) 크레딧을 차감, 소진/1년 경과 시 종료. DRM·워터마크 전 플랜 포함. (연 $149 ~ $1,599)
- **Mux**: 종량제. 저장(분당) + 전송(월 10만분 무료 후 분당) + DRM $100/월 고정 + 인코딩 1회성. 4K·시청량 늘어도 총액 거의 고정.
- 해외 결제 공통: 세금계산서 없음 → 부가세 공제 불가(실질 +10%)

## 알림톡·문자 (솔라피 / 알리고)

- **용도**: 성적 등록, 영상 지급, 결제 완료, 학부모 리포트, 클리닉 출결, 결석 안내, 신규생 계정(아이디·비번) SMS
- **방식**: LMS 서버에서 이벤트 발생 시 자동 발송

### 비용 구조 (건당 과금, 기본료 없음)
- 카카오 알림톡: **6.5~13원/건**
- 문자(SMS): 약 10~20원/건 (알림톡 실패 시 대체 발송)
- 전제: 카카오 비즈니스 채널 + 템플릿 사전 검수(2~5영업일)

## 화상 클리닉 (구글 미트 / Google Workspace)

- **용도**: 1:1 클리닉. 링크 자동 생성, 감독용 녹음(전사+AI요약), 출결 자동 판정
- **핵심**: 영상 녹화 없이 **전사 + AI 요약**(한국어) → 조교 감독·상담 기록
- **법인 계정 1개(호스트)만 유료**, 학생은 무료 참여

### 비용 구조 (계정당 월정액)
- Business Standard: **$14/계정·월** (연 약정) — 녹화·전사·AI요약 포함
- 동시 클리닉이 여러 개면 그 수만큼 좌석 추가

---

## 상담·문의·전화 (채널톡)

- **용도**: 결석생 전화 상담(녹음·요약) + 문의를 **한 곳으로** — 카카오톡·인스타 DM·LMS 위젯 통합
- 전화 자동 녹음 + STT + AI 요약 기본 포함, 상담 이력 학생별 기록

### 비용 구조 (월 플랜 + 사용량)
- 플랜: **월 27,000원** (연결제, 고객 1,000명·상담원 2 포함)
- 전화번호 5,000원/월 + 통화료(무선 72원/분·유선 15원/분)
- 카톡 상담톡 답변 80원/건, 인스타 무료
- 상담원 3석부터 +60,000원/월
- **합계 대략 월 5~6만원**

## 교재 결제 (결제선생)

- **이미 사용 중** → LMS에 **연동/임베드**만 (신규 비용 없음, 기존 수수료 그대로)
- 학생·학부모 양측 결제 + 중복 방지, 커리큘럼당 1회
- 향후 PG 직접 연동으로 전환 여지 (설계상 열어둠)

## (참고) 모니터링 — Sentry

- **용도**: 에러 추적·AI 원인 분석 (현장 버그 대응)
- 무료 티어 있음, 유료 팀 플랜 월 $26~
- 개발측 도구 — 대표 결정 사항 아님
