# 영상 호스팅

## 요건
- 다운로드 불가
- 콘솔로 링크 찾아도 재생 불가 (DRM)
- 워터마크 (가점)
- 4K 원본
- LMS(웹/앱) 임베드

## 1안 — VdoCipher / Mux

### 기능
| | VdoCipher | Mux |
|---|---|---|
| DRM (Widevine/FairPlay) | ✅ 기본 | ✅ ($100/월) |
| 동적 워터마크 | ✅ 기본 | ❌ (정적만) |
| 다운로드 방지 | ✅ | ✅ |
| LMS 임베드 | ✅ | ✅ |
| 과금 | 대역폭(GB) | 분(시간) |

### 비용
| | 4K | 1080p |
|---|---|---|
| VdoCipher | $163 (300h) ~ $503 (1,000h) | $58 (300h) |
| Mux | ~$120 고정 | ~$110 |

- 4K → Mux (고정비, 워터마크 X)
- 1080p → VdoCipher ($58, 워터마크 O)
- 해외결제: 세금계산서 X (+10%)

## 2안 — YouTube
- 비용 $0, 4K 무료
- RPA 테스트 완료 (부여·회수 실동작)
- 32개 한도 → 초과 시 영상 사본 분할
- 코드 변경 시 공유 중단 (복구 ~1일)
- LMS 임베드 불가 (유튜브 이동 + 본인 구글 로그인)
