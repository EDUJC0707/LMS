# 영상 호스팅 검토 — VdoCipher / Mux vs YouTube RPA (2026-07-17)

> **목적**: [결정필요사항 §결정 1](결정필요사항-2026-07-15.md)의 판단 재료. PRD 6-7(영상 호스팅)·8-2(공유 한도)의 답.
> **전제**: 1시간 강의영상 30개(원본 4K), 학생 60~100명, 링크 유출 방지 필수. 시청량 시나리오 (a) 월 300시간 (b) 월 1,000시간.
> 조사: 공식 가격 페이지/API 직접 조회, 2026-07 기준. GB 환산·저장용량은 가정치(1080p ≈ 1.2GB/h, 4K ≈ 5.4GB/h) — 계약 전 파일럿 실측 권장.

## 0. 한 줄 결론 (TL;DR — 2026-07-17 요건 확정 후 갱신)

- **보안 요건(확정)**: ①다운로드 불가 ②콘솔로 URL 찾아도 재생 불가(= **진짜 DRM 필수**, 서명 URL로는 부족) ③사용자별 워터마크+기록. 영상 원본 4K.
- **YouTube "50계정 한도"는 옛말**: 실제는 2025-03부터 **약 32개에서 저장 차단**(비공식·가변). 그리고 워터마크·기록 요건 미달.
- **전수조사(글로벌 6종 + 국내 4종 + AWS 조립식) 결과 요건 충족 생존자는 셋**: **VdoCipher**(3요건 기본 포함, 공개가격, 최저가) / **Kollus**(3요건 + 화면녹화 차단, 견적제·1년 약정, 국내 인강 표준) / Gumlet Business+DRM(충족하나 $198~248/월 고가).
- 4K 스트리밍이면 GB 과금인 VdoCipher는 시청량에 비례 증가($163→$503), **판서 가독성 목적이 아니면 스트리밍은 1080p 권장**(그러면 월 $58).

## 1. YouTube 공유 한도 사실검증 (요약)

- "50" 출처 = [2011년 공식 도움말](http://web.archive.org/web/20110406145222/http://www.google.com/support/youtube/bin/answer.py?answer=157177) ("up to 50 other users") → 2013년경 삭제, [현행 문서](https://support.google.com/youtube/answer/157177?hl=ko&co=GENIE.Platform%3DDesktop)엔 한도 언급 없음
- 실제: 2025-03부터 **약 32개 초과 시 저장 불가** 보고 일치 ([커뮤니티](https://support.google.com/youtube/thread/330304572?hl=ko) · [기사](https://techissuestoday.com/youtube-private-video-email-sharing-limit/)). 공식 발표 없음, 결제로 완화 불가, 가변적
- **검증법**: 테스트 영상에 이메일 33개 추가 저장 시도 (10분)

## 2. VdoCipher — 연간 선불 + 대역폭 차감

**전 유료 플랜에 Widevine+FairPlay DRM, 동적 워터마크(학생 이름·전화 오버레이), 도메인 제한, 4K 멀티비트레이트 기본 포함** — DRM이 애드온이 아님. CDN은 AWS CloudFront(서울 엣지 보유).

|---|---|---|---|---|
| Starter | $149 | 1 TB | 100 GB | $0.11/GB |
| Value | $399 | 2.5 TB | 200 GB | $0.10/GB |

- 선충전 방식이라 자동 초과과금 없음. 무료 체험 30일/5GB(FairPlay 제외).
- **연동**: Django에서 REST 1회(`POST /api/videos/{id}/otp`, 워터마크 annotate 포함) → React 공식 플레이어. **가장 손이 덜 감.**

## 3. Mux — 분 단위 종량제 + DRM 애드온

- 인코딩(plus 품질, DRM 필수 전제): 1080p $0.03125/분 · 4K $0.10/분 (1회성 — 30시간 기준 1080p ~$56, 4K ~$180)
- 스토리지: 1080p $0.003/분·월 (30시간 = $5.40) · 4K $0.0096/분·월 ($17.28). 90일 미시청 시 콜드 스토리지 할인
- **전송: 매월 첫 100,000분 무료** → 두 시청 시나리오(18,000/60,000분) 모두 **전송비 $0**
- **DRM: $100/월 고정 + 재생당 $0.003** ← 사실상 바닥값. Signed URL·도메인 제한은 무료지만 워터마크는 자체 구현 필요
- **월 합계: 1080p ~$107–110 · 4K ~$119–122** (시청량 둔감 — 대량에 강함)
- 연동: PyJWT 서명 토큰 2종 + `@mux/mux-player-react`. 문서/DX 우수, FairPlay는 Apple 개발자 인증서 필요.

**추가 판단 재료**:
- **세금**: 해외 SaaS 직접 결제는 세금계산서 불가 → **부가세 매입세액공제 불가(실질 +10%)**. 국내(Kollus·WeCandeo)는 세금계산서 가능 — 견적 비교 시 이 10%를 반영할 것
- VdoCipher 리스크: 한국 PoP 공식 명시 없음(CloudFront 서울 엣지로 추정) + 국내 실사용 후기 부재 → **무료 체험(30일/5GB)으로 국내 회선 실측 필수**
- Kollus 보너스: 해외 브라우저 DRM엔 없는 **녹화 프로그램 실시간 감지·차단**(요건 ③의 마지막 구멍인 화면녹화까지 커버)

**최종 결론(2026-07-17 — 요건: DRM 필수, 워터마크 가점, 원본 4K)**:
- **Kollus 가격 확인으로 탈락** — DRM 플랜 하한 월 ~100만원 + 1년 약정(아카이브 요금표·리셀러가·ARPU 3경로 수렴). 기능 최강이지만 학생 100명 규모엔 5~10배 과함
- **4K 스트리밍 → Mux** (월 ~$119~122 고정, 시청량 무관): DRM 견고, 워터마크 없음. 인코딩 1회성 $180
- **1080p 스트리밍 → VdoCipher Express** (월 ~$58): DRM+동적 워터마크 포함. 4K 스트리밍 시엔 $163(300h)~$503(1,000h)로 열세
- Bunny+DRM: Mux 대비 강점 없음 — 예비
**즉 남은 결정은 단 하나: 스트리밍 해상도.** 4K = Mux(워터마크 포기), 1080p = VdoCipher(워터마크 확보 + 최저가). 어느 쪽이든 무료 체험/PoC로 한국 회선 재생 품질 실측 후 확정. (해외 결제 공통: 세금계산서 불가 → 실질 +10%)

## 5. 판단 프레임

1. **반 인원이 32명을 넘는가?** 넘으면 YouTube안은 사본 분할 운영 — 자동지급(출석 트리거) 흐름이 복잡해짐
2. **스트리밍 해상도를 1080p로 합의할 수 있는가?** 가능하면 VdoCipher Express **월 ~$58(연 $699)** 로 임베드+DRM+워터마크+무한 계정이 해결 — RPA 유지보수 리스크 제거 가치로 충분히 정당화 가능한 금액
3. 4K 스트리밍 고집 또는 시청량 급증 전망이면 Mux(월 ~$110–122 고정)
4. 비용 자체를 못 받아들이면 2안(YouTube RPA) 유지 — 단 32한도 전제로 반 편성 확인 필수
