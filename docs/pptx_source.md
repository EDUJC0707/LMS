## 1. 영상 호스팅 — DRM 호스팅 vs YouTube RPA

### 용어
- **DRM**: 영상을 암호화하는 기술. 학생이 개발자도구·콘솔로 영상 주소를 빼내도 파일이 암호화돼 있어 재생 불가. 복호화 열쇠는 "로그인한 그 학생·그 기기"에만 잠깐 발급.
- **RPA**: 사람이 하던 반복 클릭 작업을 봇이 대신. 여기선 유튜브에서 학생 계정에 영상 권한 부여/회수를 봇이 자동 처리.

### 요건
- 다운로드 불가
- 콘솔로 링크 찾아도 재생 불가 (DRM)
- 워터마크 (가점)
- 4K 원본 / LMS(웹·앱) 임베드

### 1안 — DRM 호스팅

**기능**
| | VdoCipher | Mux | 네이버클라우드 |
|---|---|---|---|
| DRM | ✅ | ✅ | ✅ |
| 동적 워터마크 | ✅ | ❌ | ❌ |
| LMS 임베드 | ✅ | ✅ | ✅ (플레이어 직접 구현) |
| 과금 방식 | 대역폭(GB) | 종량(분) | 조립 종량 |

**비용 기준**: 영상 30개 × 1시간, 학생 100명, 각자 전체를 **월 2회** 시청 = **월 6,000 시청시간**

**산식**
- VdoCipher = 전송량(시청시간 × 시간당 GB) 에 맞는 연간 대역폭 플랜 ÷ 12
- Mux = 저장(분) + 전송(월 10만분 무료 초과분) + DRM $100 고정
- 네이버 = 채널 6.8만 + 트래픽(GB×84원) + DRM 20만 + MAU(100명×200원)
- *시간당 GB: 1080p 1.2GB / 4K 5.4GB (표준 가정, 강의영상은 실측 시 더 낮음)*

**비용 (월, 원화 환산 ~1,380원/$)**
| 서비스 | 1080p 월 총액 | 1인당 | 4K 월 총액 | 1인당 |
|---|---|---|---|---|
| **Mux** | **50만원** | **5,000원** | **131만원** | **13,100원** |
| VdoCipher | 87만원 | 8,700원 | 330만원 | 33,000원 |
| 네이버클라우드 | 89만원 | 8,900원 | 281만원 | 28,100원 |

→ 월 2회 시청 기준 **Mux가 최저** (전송 무료한도 + 저장·DRM 고정). VdoCipher는 워터마크를 얻는 대신 비쌈.

### 2안 — YouTube (RPA)
- 비용 **0원**, 4K 무료
- RPA 검증 완료 (부여·회수 실동작)
- **최근 32개 계정 한도** → 100명이면 영상 **사본 4개로 분할** 필요 (사본별 권한·링크 관리)
- **단점**
  - 유튜브가 코드 바꾸면 공유 중단 → 복구 ~1일
  - LMS 임베드 불가 (유튜브 이동 + 본인 구글 로그인)
  - 워터마크 없음

## 2. 클리닉 (구글 미트)

### 흐름
```
유저(학생/학부모) 캘린더에서 클리닉 신청 (당일 전까지 취소·시간수정 가능)
   ↓
LMS가 구글 미트 링크 자동 생성 (녹화·전사·AI요약 ON)
   ↓
클리닉 진행
   ↓ 종료
구글 드라이브에 자동 저장: 영상 / 전사(자막 글) / AI 요약
   ↓ LMS가 API로 수집
LMS DB 저장: 영상=드라이브 링크 / AI요약=텍스트+링크 / 전사=링크(30일 내 수집)
```

### 되는 것 (전부 API 자동화)
- 미트 링크 자동 생성, 입장 통제(학생 노크→조교 수락)
- **영상 녹화 + 전사 + AI 요약** → 전부 구글 드라이브 자동 저장
- **출결 자동 판정** (참가자 입장·퇴장 시각으로)
- 신청·취소·시간수정·캘린더 = LMS 자체 개발 (미트는 통화·기록만 담당)

### 비용
- 유료 계정은 **호스트(조교)만**, 학생은 무료 참여
- **Business Standard: 계정당 $14/월** (녹화·전사·AI요약 포함)
- **동시에 진행하는 조교 수 × $14/월** (동시 클리닉 개수만큼 계정 필요)

## 3. 채널톡 — 문의·상담·전화 올인원

채널톡 하나로 문의·상담·전화를 통합. "전화 도구"가 아니라 **CS 허브**.

- **문의 통합**: LMS 위젯 + 카카오톡 + 인스타 DM → 한 곳에서 응대
- **전화**: 발신 + 자동 녹음 + AI 요약, 학생별 통화 이력 (→ 다음 슬라이드)
- **CRM 허브**: 한 학생 밑에 문의·전화·상담 전부 통합
- **헬프센터(FAQ)**: 학부모 셀프 해결 → 문의량 감소
- **(확장 여지)** AI 자동응대 · 등록 전환 마케팅 · 내부 팀챗

## 4. 전화 (채널톡)

### 배경
- 관리자가 **결석생 상담 전화**를 직접 할 예정 (결석 사유·동보 안내·학습 대응)
- 개인 폰으로 걸면 **통화 기록이 안 남거나, 직접 기록을 LMS에 손으로 입력**해야 함
- 원하는 것: 전화 상담을 시스템으로 관리 — **통화 이력·녹음·내용이 학생별로 기록**되고 LMS로 연결

### 채널톡으로 되는 것
- LMS 화면에서 전화 발신 (학원 번호 연동 가능)
- **자동 녹음 + 전사(글) + AI 요약** 기본 포함
- 통화가 **학생별 상담 이력**으로 자동 기록 → LMS DB로 연결 (API)
- **결석생 상담 명단 LMS 자동 추출** (결석 처리 → 상담 대기열)
- **학생별 통화 횟수 LMS 표시** (예: "3회 통화")

### 비용
- 플랜: **월 27,000원** (연결제)
- 전화번호 5,000원/월 + 통화료 (무선 72원/분, 유선 15원/분)
- **합계 대략 월 5~6만원**

## 5. 알림톡 (자동 발송) _(※ 이번 pptx 빌드에서는 제외 — 문서만 유지)_

### 배경
- 현재 모든 알림(성적·영상·결제·클리닉·결석)이 **수기 발송**
- LMS 서버 이벤트 발생 시 **자동 발송**으로 전환

### 발송 시점 (PRD 정리)
| 언제 | 받는 사람 | 내용 |
|---|---|---|
| 성적 등록 완료 | 학생·학부모 | 성적표 링크 |
| **수업별 학부모 리포트** | 학부모 | 당일 성적표·누적성적·과제(워크북 사진) |
| 영상 권한 부여 | 학생 | 시청 링크 |
| 영상 만료 임박 | 학생 | 만료 사전 알림 |
| 교재 결제 완료 | 학생·학부모 | 결제 확인 |
| **신규생 계정 발급** | 학생·학부모 | 아이디·초기 비번 |
| 클리닉 승인·배정 | 학생 | 미트 링크 |
| 클리닉 출석/결석 | 학부모 | 출석·결석 처리 알림 |
| 노쇼 경고 | 학생·학부모 | 노쇼 누적(2회 제한) |
| 동보 처리 | 학생·학부모 | 결석보강 영상 지급 |
| 결석 상담 안내 | 학부모/학생 | 상담 안내 |

### 채널
- **카카오 알림톡** = 위 대부분 (정보성, 건당 발송)
- **문자(SMS)** = **신규생 계정 발급만** (아직 카톡 채널 친구 아님)

### 방식
- **솔라피/알리고 등 알림톡 API로 서버 직접 발송** (채널톡 아님 — 발송 성공·실패를 LMS에서 추적)
- 전제: 카카오 비즈니스 채널 + 템플릿 사전 검수(2~5영업일)

### 비용
- 알림톡 **6.5~13원/건**, SMS 약 10~20원/건
- 학생 100명 기준 월 약 2,000~3,000건 추정 → **월 약 2~4만원**
- 학생 수·수업 횟수에 비례 (최다 항목 = 수업별 학부모 리포트)
