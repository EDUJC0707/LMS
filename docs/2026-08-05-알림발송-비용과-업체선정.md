# 알림 발송 — 비용 산정과 업체 선정 (2026-08-05)

> PRD 3.1.2·6-8·9.4 의 "①카카오 알림톡 발송비" 항목에 숫자를 넣는다.
> **발송량은 전부 추정치다** — 발송 시점 전체 목록(8-17)이 확정되면 다시 계산해야 한다.

---

| | |
|---|---|
| **업체** | **알리고(Aligo)** — 대표가 이미 카카오톡 발송에 쓰고 있다 |
| **주 채널** | 카카오 알림톡, 실패 시 문자 대체발송 |
| **단가** | 알림톡 6.5원 **+ 부가세 = 7.15원**. 구간 할인 없는 고정가 |
| **월 비용(수강생 1,000명 기준)** | **약 15~20만원** |
| **연 비용** | 약 185~240만원 |
| **실패 건** | **과금 안 됨** — 자동 환불 |

솔라피 대신 알리고를 쓴다. 근거는 두 가지다 — **대표가 이미 쓰는 계정이라 발신번호
사전등록·카카오 채널 연동이 이미 끝나 있고**(리드타임 최대 항목 두 개가 사라진다),
단가도 더 싸다.

## 2. 단가 (알리고 서비스 소개서, 2026-08-05 확인)

**전부 부가세 별도다.** 실제로 나가는 돈은 ×1.1 이다 — 아래 표의 오른쪽 열을 쓴다.

| 종류 | 공시 단가 | **실부담(VAT 포함)** | 길이 |
|---|---|---|---|
| **카카오 알림톡** | **6.5원** | **7.15원** | 최대 1,000자 |
| 친구톡 텍스트형 | 12.5원 | 13.75원 | 최대 1,000자 |
| 친구톡 이미지형 | 19.5원 | 21.45원 | 최대 400자 |
| 문자 SMS | 8.4원 | 9.24원 | 90byte(한글 45자) |
| 문자 LMS | 25.9원 | 28.49원 | 2,000byte |
| 문자 MMS | 60원 | 66원 | 이미지 포함 |

**단가에 구간 할인이 없다 — 충전 금액과 무관하게 6.5원 고정이다.** 소개서의 비교
견적서가 5만원~100만원 전 구간에서 같은 단가를 쓴다(5만원 7,692건 = 100만원 153,843건
÷ 20). 솔라피가 발송량 구간별로 13→10→8원으로 내려가는 것과 다른 구조다.
**우리 규모에서는 알리고가 모든 구간에서 싸다**(솔라피 최저 구간 8원 > 6.5원).

> **"문자 대비 75% 저렴"의 기준은 25.9원**이다. 소개서가 `25.9원 vs 6.5원` 으로 직접
> 비교하고 있다(6.5 ÷ 25.9 = 25.1%). SMS(8.4원) 대비로는 23% 다. 우리가 보내는 성적·
> 리포트 안내는 45자를 넘어 어차피 LMS 구간이라 **이 비교가 우리에게는 맞다.**

**친구톡은 우리 것이 아니다.** 광고성 메시지라 채널 친구에게만 나가고 야간 발송이
막힌다(20:00~익일 08:00). 우리 알림은 전부 정보성이라 알림톡이다.

## 3. 발송량 추정 — 근거

**학생 1명당 주간 발송 건수**(주 1회 수업 전제):

| 알림 | 대상 | 주당 | 비고 |
|---|---|---|---|
| 성적 등록 | 학부모 | 1 | 수업 당일 |
| 수업 리포트 | 학부모 | 1 | 당일 성적표·누적·과제(3.1.2) |
| 영상 권한 지급 | 학생 | 1 | 출석 자동지급 |
| 영상 만료 예고 | 학생 | 1 | D-2(8.1-1) |
| 클리닉(대상 안내·리마인더·출결) | 학생 | 0.75 | 3건 × 대상률 25% 가정 |
| 결석 상담·동보 | 학부모 | 0.2 | 결석률 10% 가정 |
| 결제 | 학부모 | 0.1 | 커리큘럼 10주에 1회 |
| **합계** | | **약 5건** | |

월 환산 = 5 × 4.3주 ≈ **21.5건/명/월**

**가정한 것**(틀리면 여기부터 고친다): 주 1회 수업 · 클리닉 대상률 25% ·
결석률 10% · 성적과 리포트를 별도 발송. 성적·리포트를 한 통으로 묶으면 20% 줄고,
클리닉 리마인더를 빼면 5% 줄어든다.

## 4. 규모별 비용 (알림톡 7.15원 = 6.5원 + VAT)

전량 알림톡으로 나간다는 가정:

| 수강생 | 월 발송 | 월 비용 | 연 비용 |
|---|---|---|---|
| 300명 | 약 6,500건 | 약 4.6만원 | 약 56만원 |
| 500명 | 약 10,800건 | 약 7.7만원 | 약 93만원 |
| **1,000명** | **약 21,500건** | **약 15.4만원** | **약 185만원** |

**대체문자는 추가가 아니라 대체다.** 알림톡 실패 건은 **자동 환불**되므로(§7 확인 완료),
실패분은 알림톡 요금이 빠지고 문자 요금으로 갈린다. 1,000명·실패율 10% 기준:

| 대체문자가 무엇으로 과금되나 | 월 비용 |
|---|---|
| SMS(9.24원)로 과금 | 약 15.8만원 |
| LMS(28.49원)로 과금 | 약 20.0만원 |

**이 한 가지가 월 4만원을 가른다** — §7 의 유일한 미확인 항목이다.
따라서 현실 범위는 **월 15~20만원**.

초기에는 템플릿이 자리를 잡기 전이라 대체발송 비율이 더 높다 — 실측 후 보정한다.

## 5. 왜 알림톡인가 (문자 대비)

우리가 보내는 것은 성적 안내·리포트라 45자를 넘는다. 문자로 보내면 전부 LMS 다.

| | 실부담 단가 | 월(1,000명) | 연 |
|---|---|---|---|
| 알림톡 | 7.15원 | 15.4만원 | 185만원 |
| LMS 로만 발송 | 28.49원 | 61.3만원 | 735만원 |
| **차액** | | **45.9만원** | **550만원** |

연 550만원 차이다. 알림톡을 쓰는 이유는 개봉률이 아니라 **비용**이다.

**대가는 템플릿 사전 승인제다.** 알림톡은 자유 문구를 못 보낸다 — 문구를 등록하고
카카오 검수를 통과해야 발송되며, 변수만 치환된다. 8-17 이 막고 있는 것이 정확히 이것이다.

## 6. 왜 알리고인가 (솔라피 대비)

| | 알리고 | 솔라피 |
|---|---|---|
| 알림톡 단가 | **6.5원 고정** (구간 할인 없음) | 13원(~1만건) / 10원(1만~10만) / 8원(10만~) |
| SMS | 8.4원 | 8~10원 |
| LMS | 25.9원 | 27~30원 |
| 실패 건 과금 | **자동 환불** | 미확인 |
| 인증 | `key` + `user_id` 평문 파라미터 | HMAC-SHA256 서명 |
| 공식 SDK | 없음(REST 직접) | 있음(다국어) |
| 별도 계약서 | **없음** | — |
| **발신번호 등록** | **이미 완료**(대표 사용 중) | 신규 신청 필요 |
| **카카오 채널 연동** | **이미 완료 가능성 높음** | 신규 신청 필요 |

**알리고는 모든 발송량 구간에서 싸다.** 솔라피는 월 10만건을 넘겨야 8원이 되는데
그래도 6.5원보다 비싸다. 우리 규모(월 2만건대)에서는 솔라피 10원 구간이라
**1,000명 기준 연 차액 약 100만원**(알리고 185만원 vs 솔라피 284만원, 둘 다 VAT 포함).

하지만 **결정 이유는 단가가 아니라 리드타임**이다. 발신번호 사전등록은 통신서비스
이용증명원 등 서류 심사가 붙고, 카카오 비즈니스 채널 인증도 별도 심사다. 대표 계정을
쓰면 둘 다 건너뛴다.

인증 방식이 단순한 것도 실무에서 유리하다 — 서명 오류로 401 이 나는 부류의 디버깅이 없다.

> **업체 교체 비용은 코드가 아니라 템플릿에 있다.** 알림톡 템플릿은 발송대행사를 통해
> 등록·검수되고 템플릿 코드가 그 대행사 계정에 묶인다. **승인 후에 업체를 바꾸면 전량
> 재등록·재검수다.** 8-17 이 도착해 템플릿 등록이 시작되기 전인 지금이 바꿀 수 있는
> 마지막 시점이라 지금 정한다.

코드 쪽 교체 비용은 사실상 없다 — 채널 어댑터 계약(`apps/notifications/channels.py`)
뒤에 업체가 있어서 **새 어댑터 파일 1개 + 설정 1줄**이면 끝난다. 재시도·상태 전이·
발송내역·재발송은 손대지 않는다.

## 7. 확인 결과

- [x] **6.5원은 상시 단가다** — 소개서 비교 견적서가 충전액 5만원~100만원 전 구간에
      같은 단가를 적용한다. **구간 할인 자체가 없다.** 단, **부가세 별도**라 실부담은
      7.15원이다(2번 표 반영 완료)
- [x] **실패 건은 과금되지 않는다** — *"발송이 정상적으로 이뤄지지 않은 경우 해당 금액을
      자동으로 환불 처리"*(소개서 02 가격). **그래서 재시도 상한 5회를 낮출 이유가 없다.**
      실패 사유·내역도 조회 가능하다
- [x] **별도 계약서가 없다** — *"비즈니스 인증을 받은 카카오톡채널 아이디만 있으면 로그인
      후 즉시 카카오톡 기능 사용 가능. Web/API 플랫폼 모두 별도의 계약서가 없습니다."*
      대표 계정을 쓰는 경로가 그만큼 빠르다
- [ ] **대체문자(failover)가 SMS 로 과금되나 LMS 로 과금되나** — **유일하게 안 풀린 것.**
      소개서·FAQ 에 없다(FAQ 페이지는 자바스크립트 렌더라 본문을 못 읽었다).
      월 4만원이 갈리므로 가입 시 문의한다 (cs@alipeople.kr · 02-511-4560)
- [ ] **대표 계정을 같이 쓸지 별도 계정을 팔지** — 같이 쓰면 준비가 빠르고, 따로 파면
      학원 발송과 LMS 발송이 분리된다(대표 결정 대기)

## 8. 이 문서를 다시 써야 하는 시점

**8-17(발송 시점 전체 목록) 도착 직후.** 3번의 발송량 추정이 통째로 그 목록에서
나오는 값이라, 목록이 오면 항목별 실제 건수로 다시 계산한다. 지금 숫자는 "대략 이 자릿수"를
잡기 위한 것이다.
