# 확정 사항

> 대표와의 대화에서 **결정된 것만** 모은다. PRD 는 제품 요구사항 전체를 서술하는
> 문서라 결정이 문단 속에 묻혀 다시 찾기 어렵다 — 이 파일은 "그래서 뭘로 정했지"에
> 한 줄로 답하는 자리다.
>
> **규칙**
> - 결정된 것만 적는다. 검토 중·후보·아이디어는 여기 오지 않는다(`.claude/to-do.md` 로)
> - 뒤집힌 결정은 지우지 말고 **뒤집혔다고 표시**한다 — 왜 바뀌었는지가 다음 판단의 근거다
> - 각 항목에 **확정일**과 **대표 원문**(있으면)을 남긴다
> - 구현이 이 파일과 어긋나면 **이 파일이 맞다**. 코드를 고친다
>
> 최종 갱신: 2026-08-04

## 1. 식별자

| | 형식 | 유일한가 | 바뀌나 |
|---|---|---|---|
| **원번** `unique_id` | `{이름}{휴대폰 뒷4}` — `김하늘0001` | **아니오** | 발급 시 계산 후 고정 |
| **로그인 아이디** `login_id` | 원번과 같되 겹치면 접미사 | 예 | 불변 |
| `student_id` | DB PK | 예 | 불변 |

**충돌 접미사** — `a` `b` `c` … `z` 중 **`p` 제외**(학부모 아이디가 `{학생아이디}p` 라
겹친다). 25개를 넘으면 두 글자로 확장하되 **끝자리가 `p` 인 것은 건너뛴다**
(`pa`·`pb` 는 쓰고 `ap`·`bp` 는 안 쓴다 — `ap` 는 `…a` 학생의 학부모 자리다).

**학부모는 접미사가 없다.** 자녀 아이디에서 파생되므로 자녀가 유일하면 자동으로 유일하다.

> **원번이 겹치면** OMR·워크북 매칭에서 후보가 여러 명 뜨고 **조교가 화면에서 고른다.**
> 지면에 적히는 값은 접미사가 없어 확정된 원번과 다를 수 있다 — 그래서 인식값은
> **"예비값"**이고, 확정은 사람이 한다.

- **2026-07-30 확정**: 원번 = 로그인 아이디와 같은 축. 원문 *"원번도 같게 하자 로그인 아이디와"*
- ~~2026-07-29: 원번 = `학년+이름+뒷4`~~ → **뒤집힘**(같은 날). 지면에 들어오는 것이 곧
  원번인데 학년을 넣으면 지면과 어긋난다
- ~~2026-07-15 PRD: 원번 = 학년1+전화뒷4 숫자 5자리, **불변**~~ → **뒤집힘**

## 2. 출결

**출석 / 결석 / 결석(동보) / 결석(현보)** — 담임이 직접 찍는다.

- **동보** = 동영상 보강. **현보** = 현장 보강(다른 수업 학생이 우리 수업으로 옴)
- **지각 없음**(2026-07-30). 시험을 **수업 초반**에 보므로 지각하면 OMR 카드가 안
  들어온다 → 성적이 **"시험 미제출"**로 나가는 것으로 드러난다. 출결 값으로 두면
  같은 사실이 두 곳에 갈린다
- **퇴원은 출결 값이 아니다.** 학생 상태(`enrollment_status`)에 한 번만 저장하고,
  출결 화면에서는 명단에 남아 `퇴원` 으로 표시된다. 원문 *"한번에 찍고 그 이후에는
  이미 퇴원함"*. 회차마다 찍게 하면 "3회차는 퇴원인데 5회차는 출석"이 저장된다

## 3. 복습영상(동보)

- **그 수업에 출석한 학생 전원**이 볼 수 있다
- **결석한 학생**은 동보를 신청하면 볼 수 있다
- 시청 권한 **7일 만료**

### 호스팅 — Mux (2026-07-30 확정) · **4K 전제 폐기 (2026-08-04)**

> **촬영 원본이 1080p 다.** 4K 로 올린 줄 알았던 파일을 Mux 자산 정보로 확인하니
> 전부 `resolution_tier: 1080p` 였고, `max_resolution_tier: 2160p` 를 요청해도 HD 가
> 나왔다(Mux 는 업스케일하지 않는다). 대표 확인 후 **1080p 로 확정**.
> 아래 "4K고 무조건 DRM" 중 **4K 부분은 폐기**, DRM 은 유지.
> 등급은 **premium** — 실측상 1080p 비트레이트가 plus 의 1.7배(6.55 vs 3.84 Mbps)이고
> 회선이 나쁠 때 바닥이 270p 가 아니라 360p 다. 판서 글씨가 여기서 갈린다.
> 근거: `docs/2026-08-04-영상호스팅-비용재계산.md`

> ⚠ 아래 수치는 **재계산으로 어긋난 것이 확인됐다** — `docs/2026-08-04-영상호스팅-비용재계산.md`.
> "월 1,600시간"은 원생 133명분(설계 전제 1,000명과 7.5배 차) · "월 11~17만원"은
> 인코딩 상각·라이브러리 스토리지·부가세 10%를 뺀 값(실제 30명에서도 월 33만원).
> **업체 결론(Mux)은 유지되나 현재 규모에선 두 업체 차이가 월 3~6만원이라 가격으로
> 고를 수 없다.** 결정에 필요한 미결 항목은 그 문서 §8.

**4K + DRM 무조건.** 원문 *"4K고 무조건 DRM할거야"*.

| | 값 |
|---|---|
| 연간 녹화 | 100시간 (4K) |
| 예상 월 시청 | 1,600시간 |
| 예상 월 비용 | **11~17만원** |

- 월 1,600시간 = 96,000분으로 **무료 구간 10만 분의 96%** — 여유 4%뿐이고 Mux 는
  버퍼링된 구간도 과금한다. 11만원은 최선의 경우다
- **미확인**: 선불 크레딧($20 → $100)이 DRM 접근료 $100 에 적용되는지. 적용되면
  11만원, 아니면 17만원. Mux 에 직접 물어야 한다
- VdoCipher 는 GB 과금이라 4K 에서 월 55만원 이상 — 4K 가 요건인 이상 탈락
- **DRM 액세스 요청은 런칭 직전에**(2026-07-30 대표: "아직 돈내기 싫어서"). 요청 조건이
  유료 플랜 업그레이드라 그 시점부터 과금이 시작된다. 그 전까지는 무료 계정으로
  재생 품질만 확인한다 — 단 **본 라이브러리는 그때 올리면 안 된다**: 무료 등급(`basic`)에는
  DRM 을 걸 수 없어 `plus` 로 다시 올려야 한다(4K 100시간 재인코딩 약 $600)

### 재생 환경 — 웹만 (2026-07-30)

아이패드 + PC + 핸드폰, **전부 브라우저**. 앱 없음. 사파리 "홈 화면에 추가" 정도.

### 기간 — 두 개를 섞지 말 것

| | 무엇 | 값 |
|---|---|---|
| **창구 시작** | 언제부터 신청할 수 있나 | **권한 부여 시점**(대상자 판정 확정). 시험 당일일 수도, 며칠 뒤일 수도 |
| **창구 끝** | 받을 수 있는 **마지막 클리닉 날짜** | **시험일 + 6일** = 다음 수업 전날 |
| **신청 마감** | 그 클리닉을 언제까지 신청하나 | **클리닉 날짜의 전날** — 날짜마다 움직인다 |

```
수요반: 7/29(수) 수업·시험 → 마지막 클리닉 8/4(화) → 그 클리닉 신청 마감 8/3(월)
목요반: 7/30(목) 수업·시험 → 마지막 클리닉 8/5(수) → 그 클리닉 신청 마감 8/4(화)
```

- 원문: *"수업이 수요일이면 화요일인거고 목요일이면 수요일인거고"* ·
  *"신청마감은 계쏙 바뀌지 / 일요일 클리닉은 토요일까지"* · *"당일 신청 불가 무조건 1일전"*
- **요일로 못 박지 않는다.** 반마다 수업 요일이 달라 "다음 주 화요일" 같은 고정
  요일은 특정 반에서만 맞는다. 기준은 요일이 아니라 **간격(6일)**이다
  (2026-07-29 월요일 · 07-30 화요일로 두 번 잡았다가 두 번 어긋났다)
- **취소는 창구 밖에서도 가능**(자원 반납). 단 당일 취소는 불가
- 창구가 지난 뒤 조회는 **403 이 아니라 빈 목록** — 자격은 있는데 기간이 끝난 것이라
  다른 사실이다

## 6. 채널톡 — 연동 범위 (2026-08-04 확정)

**LMS 로 끌어오는 것은 전화 이력뿐이다.** 문의 채팅·옴니채널(카톡·인스타)·CRM 은
채널톡 안에만 두고 동기화하지 않는다. 원문 *"일단 전화 빼고 나머지 데이터는 우리 lms로
안끌고 들어올거야"* · *"나머지도 넣을 수 있어도 일단은 전화만"*.

**못 해서가 아니라 안 하는 것이다.** 조사(§4)로 Open API·웹훅 전량 동기화가 가능한 건
확인됐고 그 경로는 그대로 열려 있다 — 나중에 켜는 것은 새로 설계하는 게 아니라
**이미 아는 길을 여는 일**이라 비용이 낮다. 그래서 지금 좁게 가도 손해가 아니다.

| | 어디에 산다 | LMS 가 하는 일 |
|---|---|---|
| **전화 이력**(결석 상담) | 채널톡 + **LMS** | 상담 기록에 연결(PRD 9.2·8-18) |
| 문의 채팅·카톡·인스타 | 채널톡만 | 없음 |
| 고객 프로필(CRM) | 채널톡만 | 없음 |

- **Open API·웹훅 전량 동기화 계획은 여기서 빠진다.** 조사 문서(`local/sources/research/
  2026-07-17-채널톡-도입검토.md` §4)가 잡아 둔 물량이 전화 한 갈래로 줄었다
- **업체 종속 금지 계약이 걸리는 자리도 하나로 줄었다** — 채널톡 이름이 DB 에 닿을 수 있는
  곳은 `absence_counselings` 뿐이다. 거기도 선례대로 `provider` + 중립 참조 ID 로 받는다
  (컬럼은 연동 착수 때 판다 — 지금 파면 안 쓰는 칸이다)
- **대가: 안 끌어오는 것에는 백업이 없다.** 채널톡 약관에 미납·해지 시 삭제 조항이 있고
  무료 플랜은 **최근 30일 상담만 조회**된다. 랜딩 문의는 30일 지나면 사라진다고 보면 된다.
  유료 플랜의 보존 기간은 문서에 명시가 없어 `확인 필요`

### 요금 — 가입은 지금, 과금은 전화부터
랜딩 위젯은 **무료 플랜의 기본 채팅**이라 돈이 안 나간다.
**전화(미트 콜)는 유료 플랜이 조건** → 그때 얼리 스테이지(연결제 월 27,000원)로 올린다.
번호 5,000원/월 + 발신 무선 72원/분이 실비로 붙는다.

  실제로 걸린다. 법정대리인 동의 의무가 학원 책임으로 떨어지는 구조
  (`local/sources/research/2026-07-17-채널톡-도입검토.md` §5·§7)

- **1차 오픈 범위**(PRD 8-14)
- 현보로 온 학생을 **명단에 어떻게 편입**할지 — 원래 그 회차 명단에 없는 사람이다
- 졸업 처리 — N수(학년 4) 다음이 없다
