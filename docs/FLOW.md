## 1. Teacher 가 반을 만든다

**만드는 단위는 `반`이다.** "강좌를 만들고 학생을 넣는다" 가 아니라, **반 하나가 곧 하나의
수업 묶음**이고 그것이 자기 일정을 갖는다.

### 입력 항목

| 항목 | 형태 | 예 |
|---|---|---|
| **구분** | 드롭다운 | `수능` · `내신` |
| **과목** | 드롭다운 (구분에 종속) | 아래 표 |
| **수강반명** | **직접 입력** (유일한 자유 입력) | `목 6.5 대치러셀` |
| **개강일** | 날짜 | `2026-09-04` |
| **총주차** | 숫자 | `10` |

**요일은 개강일에서 얻는다** — 따로 입력받지 않는다.

### 구분 ↔ 과목

과목 목록은 구분에 종속된다. 넷이 전부이고 겹치지 않는다.

| 구분 | 과목 |
|---|---|
| **수능** | 통합과학 |
| **내신** | 일반선택 생명과학 |
| | 진로선택 생명과학 — 세포와 물질대사 |
| | 진로선택 생명과학 — 생물의 유전 |

### 같은 과목에 반이 여럿 붙는다

```
수능 · 통합과학
  ├ 반  목 6.5 대치러셀    개강 9/4   10주
  └ 반  화 6.5 대치러셀    개강 9/2   10주
```

**반끼리는 독립이다.** 목반이 밀려도 화반은 그대로다.

---

## 2. 만든 뒤에도 전부 고칠 수 있어야 한다

여기가 이 설계에서 제일 어려운 부분이다. **한 번 만들면 끝이 아니다** — 개강일도,
총주차도, 반 이름도 수업이 도는 도중에 바뀐다.

### 주차가 밀릴 때: 날짜가 움직이고 번호는 그대로다

휴강으로 한 주가 밀리면 **(가)** 로 간다.

| | |
|---|---|
| **(가) 채택** | `3주차`는 계속 `3주차`이고 **날짜만** 뒤로 간다. 뒤 주차도 함께 밀린다. 총 10주는 유지 |
| ~~(나) 기각~~ | ~~그 주를 비우고 다음 수업이 4주차가 된다~~ |

즉 **주차 번호는 고정 좌표**이고 날짜가 그 위를 움직인다. 출결·영상 권한·클리닉이
전부 주차 번호에 매달려 있으므로, 번호가 흔들리면 이미 쌓인 기록의 뜻이 바뀐다.

### 미는 것은 반 단위다

**한두 반만 밀릴 수 있다.** 같은 과목의 다른 반은 영향받지 않는다.
→ 주차는 **과목이 아니라 반에 매달려야** 한다.

### 뒤 주차가 따라 밀린다

`목 6.5` 3주차를 11/5 → 11/12 로 밀면 **4~10주차도 함께 일주일 밀린다.**
한 주만 떼어 옮기는 것이 아니다. 따라서 **종강일이 그만큼 늦어진다.**

### 1주차 = 수업 1회

한 반은 **주에 한 번** 만난다. 주차와 수업 회차가 1:1 이다.
(지금 스키마의 `WeekDayPlan.day_no` 는 주 안에 여러 날을 담을 수 있게 돼 있는데,
이 전제에서는 쓰이지 않는다.)

### 총주차는 늘릴 수만 있다

10주 → 11주는 되고, **줄이는 것은 막는다.** 이미 기록이 있는 주차를 잘라 낼 수 없다.

## 3. 무엇이 언제까지 고쳐지는가

위 규칙들을 합치면 하나로 정리된다.

> **개강 전에는 다 고칠 수 있다.
> 개강일이 지나면 반의 정체성은 잠기고, 일정만 움직인다.**

| | 개강 전 | 개강 후 |
|---|---|---|
| 구분 · 과목 | 수정 | **잠김** |
| 수강반명 | 수정 | **잠김** |
| 개강일 | 수정 | **잠김** |
| 총주차 | 수정 | 늘리기만 (줄이기 ✗) |
| 주차 날짜 | — | **민다** (뒤가 따라옴) |

### 이름을 잠그면 표기 문제가 사라진다

반 이름이 개강 후에 안 바뀌므로 **"지난 출결에 찍힌 반 이름은 옛 것인가 새 것인가"** 를
정할 필요가 없다. 그래서 이름은 **복사하지 않고 참조만 한다** — 지금은 문자열로
두 군데(`CourseEnrollment.class_name`·`Student.current_class`)에 복사돼 있어 어긋나는 중이다.

개강 **전**에 이름을 고치는 것은 자유이고, 참조라서 저절로 따라온다.

## 지금 코드와의 차이 (2026-08-12 실사)

이 흐름은 **현재 스키마로 표현할 수 없다.** 옮겨야 할 것:

| | 지금 | 필요한 것 |
|---|---|---|
| **반** | `CourseEnrollment.class_name` **문자열**(+ `Student.current_class` 에 또 한 벌) | 엔티티. 이름·개강일·총주차를 갖는다 |
| **주차** | `CourseWeek` 가 **강좌**에 매달림 | **반**에 매달려야 반별로 밀 수 있다 |
| **회차** | `ClassSession` 이 **어느 반인지 모른다** — 날짜와 학년만 있다 | 반에 매달려야 한다. 반별로 밀리면 회차도 같이 옮겨진다 |
| **구분·과목** | 없음. `Course.name` 한 칸에 뭉개 넣음 | 값집합 두 개 |
| **개강일·총주차** | 없음 | 반의 속성 |
| **잠금** | 없음 — 아무 때나 고쳐진다 | 개강일 기준으로 정체성 필드가 잠긴다 |

- 반이 문자열이라 학생 명부 검색이 `icontains` 부분일치다
  (`student_directory.py` 주석: *"반 이름 표기 흔들림 허용"* — 이미 흔들리고 있다는 뜻)
- `week_no`·`CourseWeek` 를 참조하는 파일이 **18개**다. 영상 권한(`video_admin`)·게시판·
  출결·홈 화면이 전부 걸린다
- **지금이 제일 싼 시점이다** — 운영 데이터가 데모뿐이고 아직 오픈 전이다.
  오픈 후에는 실제 출결·영상 권한을 이관해야 한다
