# 채널톡 전체 기능 & LMS 적용 검토

> 채널톡은 "상담 메신저"를 넘어 **상담 + AI + 마케팅 + CRM + 화상 + 팀협업** 플랫폼이다.
> 이 문서 = 채널톡 전 기능 카탈로그 + 각 기능의 **우리 LMS 적용 아이디어** + 비용/한도.
> 비용은 이번 리서치(2026-07) 검증치 기준. 재확인 권장 항목은 `확인 필요`.

---

## 0. 요금 체계 (먼저 이해)

**과금 = ① 플랜 월정액 + ② MU(연락처 수) 초과분 + ③ 시트(상담원) + ④ 기능별 사용량**

### 플랜
| 플랜 | 월정액(연결제/월결제) | 포함 MU | 포함 시트 |
|---|---|---|---|
| 무료 | 0 | — | 최근 30일 상담만 조회 |
| **얼리 스테이지** | **27,000 / 36,000원** | 1,000 | 기본 5 + 오퍼레이터 2 |
| 그로스 | 90,000 / 120,000원 | 3,000 | 기본 5 + 오퍼레이터 1 |
| 엔터프라이즈 | 문의 (연매출 100억↑ 필수) | 협의 | 협의 |

- **MU(Managed User)** = 연락처에 저장된 고객 수. 초과분 월: 1~1,000명 30원, ~5,000명 20원, ~2만명 10원 …
- **시트 추가**: 기본 시트 3,000원/월, **오퍼레이터 시트(채팅·전화 상담 담당) 60,000원/월** ← 상담원 3명째부터 큰 비용
- 시트 구분: **기본 시트**=팀챗·상담 열람 / **오퍼레이터 시트**=실제 채팅·전화 응대

### 기능별 사용량 단가 (플랜과 별도, 쓴 만큼)
| 기능 | 단가 | 무료 한도 |
|---|---|---|
| 카카오 알림톡 | 7원/건 | — |
| 문자 SMS / LMS | 10원 / 28원 | — |
| 카톡 상담톡 답변 | 80원/대화방(24h·동일고객 1회) | 무료플랜 월 10,000P |
| 전화번호 | 5,000원(얼리)/9,000원(그로스)/월 | — |
| 통화료 | 무선 72원/분, 유선 15원/분 (수신 무료) | — |
| 고객 ALF (AI상담) | 상담 참여당 500원 | 그로스↑ 전용 |
| 워크플로우(자동화) | 초과분 100→50→10원/실행 | 월 50건 무료 |
| 마케팅 메시지 | 초과분 5→2→1→0.5원/건 | 월 30건 무료 |
| 인스타 DM 연동 | 무료 | — |

## 1. 상담 인박스 (채팅 상담)

- **뭐하는지**: LMS 위젯·카톡·인스타에서 온 문의를 한 인박스에서 응대. 상담원 배정, 우선순위, 상담 이력, 고객별 스레드.
- **플랜/비용**: 전 플랜. 오퍼레이터 시트 수 = 동시 응대 상담원 수.
- **LMS 적용**:
  - 학생·학부모 1:1 문의 (PRD 3.3.2 — 자체개발 대신 이걸로)
  - 질답도 여기로 유입 가능(공개 게시판은 별도 유지)
  - 모든 문의가 학생 프로필에 이력으로 쌓임 → 상담 맥락 파악

## 2. 옴니채널 연동

- **뭐하는지**: 외부 채널 문의를 채널톡 인박스로 통합.
- **채널별**: 카카오톡 상담톡(비즈인증 필요, 답변 80원/대화방) · 인스타 DM(비즈계정, 60일 재인증, **무료**) · 네이버 톡톡 · 라인 · 이메일 · 웹 위젯 — **전부 얼리 스테이지부터**.
- **LMS 적용**:
  - 학부모가 **카톡·인스타로 편하게 문의** → 관리자는 채널톡 한 곳에서 응대
  - "학원 어디로 연락하지?" 문제 해소 (단일 창구, 채널 무관)
  - 외부 채널 대화도 API로 LMS DB 동기화 가능

## 3. 전화 (미트 콜)

- **뭐하는지**: LMS/앱에서 발신·수신, **자동 녹음 + STT(전사) + AI 요약** 무료 포함, 학생별 통화 이력.
- **비용**: 번호 5,000원/월 + 무선 72원/분.
- **LMS 적용**: 결석생 상담 전화(pptx 3번 섹션). 통화 횟수·녹음·요약이 학생 상담기록으로 자동 연결.

## 4. 화상 미팅 (미트 Meet 영상)

- **뭐하는지**: 채널톡 내장 화상회의. 무료 플랜도 **최대 30명·1시간** 제공, 화면공유.
- **LMS 적용 (신규 아이디어)**:
  - **클리닉을 구글 미트 대신 채널톡 미트로?** — 검토 가치 있음. 단 구글 미트는 전사·출결 API·Drive 저장이 강력하므로 **클리닉은 구글 미트 유지 권장**, 채널톡 미트는 가벼운 상담/설명회 Q&A용 보조.
  - 학부모 화상 상담(간단한 건)에 활용 가능.
- `확인 필요`: 유료 플랜의 미트 인원·시간 상향 한도, 녹화 저장 방식.

## 5. ALF (AI 에이전트 / AI 상담) ★ 우리가 안 적은 것

- **뭐하는지**: AI가 고객 문의에 **자동 응답**. 학원 자료(FAQ·문서) 학습 후 24시간 무인 답변. "고객 ALF"(엔드유저 대상) / "팀 ALF"(상담원 보조).
- **비용**: 고객 ALF = **상담 참여당 500원**, **그로스 플랜(월 90,000원)↑ 전용**.
- **LMS 적용 (신규)**:
  - 학부모 반복 문의 자동응대: "결제 어떻게 해요?", "성적표 어디서 봐요?", "이번 주 수업 일정?", "환불 규정?"
  - 야간·주말 문의를 AI가 1차 처리 → 관리자 업무 경감
  - 판단: **초기엔 불필요**(그로스 승급+건당 500원). 문의량이 많아지면 도입 검토. 1차 오픈 범위 밖 권장.

## 6. 챗봇 / 워크플로우 (자동화) ★ 우리가 안 적은 것

- **뭐하는지**: 이벤트·조건 트리거로 자동 메시지/분기/봇 시나리오. 월 50건 무료.
- **비용**: 초과분 실행당 100→50→10원.
- **LMS 적용 (신규)**:
  - 서버 이벤트(결석 발생, 결제 미완료 등)를 채널톡에 쏴서 자동 안내
  - "처음 위젯 연 학부모에게 이용 안내 자동 발송"
  - 단, **트랜잭셔널 알림톡(성적·클리닉)은 워크플로우 말고 솔라피 직접 발송이 정석**(pptx 4번) — 여기선 CS/마케팅 자동화만.

## 7. 마케팅 (캠페인 / 세그먼트 / 팝업) ★ 우리가 안 적은 것

- **뭐하는지**: 고객 세그먼트별 타깃 메시지, 사이트 팝업, 캠페인 자동발송. 마케팅 메시지 월 30건 무료.
- **LMS 적용 (신규)**:
  - **미등록생(예비등록) → 등록 전환** 유도 메시지 (랜딩·잠재고객 전환, PRD 3.3.3와 연결)
  - 설명회·이벤트/굿즈 안내(PRD 게시판 이벤트)
  - 교재 결제 미완료 학부모 리마인드
  - 시즌 팝업(모의고사 시즌 등)
  - 판단: 랜딩·마케팅은 **1차 오픈 후순위**지만, 채널톡에 이미 있으니 나중에 무료로 얹을 수 있음.

## 8. CRM / 고객 데이터

- **뭐하는지**: 고객 프로필(연락처=MU), 커스텀 필드, 세그먼트, 이벤트 추적.
- **LMS 적용**:
  - **memberHash로 LMS 로그인 학생·학부모를 채널톡 프로필과 연결** → 문의·전화·상담이 한 사람 밑에 통합
  - 커스텀 필드에 학생ID·학년·반·등록상태 넣어 상담 시 즉시 파악
  - 주의: **MU가 늘면 과금** — 학생+학부모 합쳐 1,000명 넘으면 명당 30원. 규모 커지면 비용 항목.

## 9. 서포트봇 / 헬프센터 (도움말 문서) ★ 우리가 안 적은 것

- **뭐하는지**: FAQ·도움말 문서를 셀프서비스로 제공, AI 문서 검색.
- **LMS 적용 (신규)**:
  - 학원 FAQ(환불·수업 규정·계정 문제·앱 사용법)를 문서화 → 학부모 셀프 해결 → 문의량↓
  - "처음 로그인 어떻게?", "구글 계정 등록법"(영상 시청용) 등 온보딩 가이드

## 10. 팀챗 (내부 협업 메신저) ★ 우리가 안 적은 것

- **뭐하는지**: 상담원(직원) 내부 채팅, 멘션, 상담 건 공유. **기본 시트**로 사용.
- **LMS 적용 (신규)**:
  - 관리자·조교 내부 커뮤니케이션(카톡 단톡 대체 가능)
  - 특정 상담·학생 건을 내부 공유·인계
  - 판단: 이미 다른 협업툴 쓰면 불필요. 상담 맥락 공유엔 편리.

## 11. 통계 / 리포트

- **뭐하는지**: 상담 KPI(응답시간·해결률), 전화 모니터링 대시보드, 커스텀 리포트.
- **LMS 적용**:
  - 결석 상담 KPI(통화 수·응답률) 관리 — 단 "학생별 통화 횟수"는 raw data·API 가공 필요(pptx 3번 각주)
  - 상담 운영 현황 파악

## 12. 개발 연동 (API / 웹훅 / SDK)

- **Open API**: 상담·메시지·고객 조회 → LMS DB 동기화
- **웹훅**: 새 상담/메시지 이벤트를 Django로 push
- **JS SDK**: React 위젯 부트 + `memberHash`(서버 서명)로 로그인 사용자 안전 연동
- **LMS 적용**: 문의·전화·상담 기록을 LMS로 수집(기록 원본=LMS 원칙), 위젯을 학생/학부모 화면에 임베드

## 예상 월 비용 (학원 규모: 고객 ≤1,000, 상담원 2)

- 기본: 얼리 스테이지 **27,000원**(연결제)
- 전화: 번호 5,000 + 통화료(월 100통×3분 무선 ≈ 21,600)
- 알림톡은 채널톡 아닌 솔라피로(pptx 4번) → 여기 미포함
- 카톡 상담톡: 문의량 따라(예 월 200건 × 80원 = 16,000)
- **합계 대략 월 6~8만원** (ALF·마케팅 본격 도입 전)
- 확장 시 큰 변수: ①상담원 3명↑(오퍼레이터 +60,000/월) ②MU 1,000명 초과 ③그로스 승급(ALF 쓸 때)

## 결론

- **1차 오픈에 바로 쓸 것**: 상담 인박스 + 옴니채널(카톡·인스타) + 전화 + CRM/API 연동 + 헬프센터 → 이게 "문의·상담·전화 통합"의 핵심이고 월 6~8만원.
- **2차 이후 무료로 얹을 것**: 워크플로우, 마케팅/세그먼트(등록 전환), 팀챗.
- **후순위(비용 발생)**: ALF(AI상담) — 문의량 많아지면.
- 채널톡을 "전화 도구"로만 보면 저평가. **문의 창구 + CS 자동화 + 마케팅 + CRM 허브**로 쓰면 자체개발 부담을 크게 덜어준다.
