# 랜딩 스펙 — 히어로 한 화면

2026-07-28 확정. 이전 시도(스크롤 스크러빙 영상 시퀀스)는 폐기했다. 지금은 **훨씬 단순하다.**

---

## 0. 한 줄 요약

**검은 화면. 헤드라인 두 줄. 오른쪽에 한종철. 배경 어둠 속에 통합과학 6개 대단원이 숨어 있고, 건드리면 드러난다.**
그 아래로 커리큘럼 · 정오표 · 컨택트 세 섹션이 색을 바꿔가며 이어진다. 채널톡이 내내 떠다닌다.

├──────────────────────────────────────────────────────┤
│                                                       │

│                                     ┌──────────┐     │

**히어로는 한 화면이다.** 스크롤 애니메이션 없음. 아래 섹션은 §7.

## 2. 네비게이션 바

- 배경: **순검정** (히어로와 이어져 경계가 없다)
- 왼쪽: 로고 — `한종철 통합과학` + 섹션 링크 `커리큘럼` `정오표` `문의하기`
- 오른쪽: **[ 로그인 ]** 버튼 하나

**로그인 전에는 "LMS"를 걸지 않는다**(2026-07-28 사용자 지시). 비로그인 방문자에게
LMS 는 제품 내부 명칭이고, 이 화면이 파는 것은 강의다.

nav 에도 **같은 먼지가 뜬다.** nav 는 항상 불투명 검정이라 그 아래 히어로 먼지밭을
가로로 잘라 먹는다 — 이어 주지 않으면 화면 맨 위 64px 만 텅 빈 띠로 남아 "덮개"라는
전제가 깨진다. 밀도는 개수가 아니라 **면적당으로** 맞춘다(실측 nav 6.46 vs 히어로 6.11
per 천px²). **커서에 반응하지 않고 애니메이션도 하지 않는다** — 연속성만이 목적이고,
화면 맨 위에서 계속 움직이는 것은 그 자체가 방해다.

섹션 링크는 아래 세 섹션으로 그냥 내려보내는 앵커다. 390px 에서는 로그인 버튼을
20px 침범하므로 접는다 — 스크롤하면 순서대로 나오므로 이동 수단이 사라지지 않는다.

## 3. 헤드라인 — 확정

```
통합과학도
철두철미하게
```

**확정**(2026-07-28). 텍스트 2줄, 왼쪽 배치. 이미지 아님.

지어낸 카피가 아니라 **한종철이 메가스터디에서 이미 쓰는 슬로건 원문**이다
("생명과학도 철두철미하게!" / "통합과학도 철두철미하게!"). 그래서:

- **검증이 끝나 있다** — 본인 브랜드로 이미 굴러가는 말
- **이름의 '철'과 교재 브랜드**(철두철미 개념완성/실전모의고사/완자)가 한 줄로 꿰인다
- 조사한 과학강사 38명의 지배적 수법(이름을 문장에 녹이기 — 장풍 "정상을 향한 바람",
  백호 "Yes 백호!")과 같은 계열이면서, **그중 유일하게 태도가 아니라 방식을 말한다**
- 조사 근거상 "관리"라는 명사는 학부모에게 동네학원 언어로 읽혀 지뢰인데,
  "철두철미"는 같은 뜻을 사자성어로 우회한다
- **'도'** 한 글자가 생명과학 이력을 보증으로 바꾼다 — 전환기 랜딩의 핵심 부담을 조사가 해결

> 후보 10개를 뽑아 비교한 기록: `local/landing-refs/03-헤드라인-후보.md`
> (본인 목소리·라이벌·전환기·학부모·카피기술 5개 관점 × 6개 = 30개 → 10개)
> 결과적으로 **지어낸 것보다 이미 쓰던 말이 이겼다.**

### 서체 — SUIT Variable **확정**(2026-07-28)
`cdn.jsdelivr.net/gh/sun-typeface/SUIT@2` 가변 1파일로 100~900을 쓰고 헤드라인은 900.
**본체 앱(`frontend/index.html`)과 같은 서체다** — 랜딩과 로그인 후 화면이 다른 글씨로
보이면 같은 서비스로 안 읽힌다. 교체를 검토했으나 그대로 가기로 했다.

### 조판 메모
- 줄바꿈은 `통합과학도` / `철두철미하게`. 2행이 1행보다 길어 왼쪽 정렬에서 계단이 진다
- **부제·설명을 붙이지 않는다.** 이 2줄과 사진이 히어로의 전부다
- 두 줄 사이는 `line-height` 가 아니라 **flex `gap`(`--h1-gap`, 기본 .14em)** 이
  벌린다. line-height 는 글자 위아래 여백을 같이 키워서 "두 줄 사이"만 따로 조절할
  수가 없다. em 이라 글자 크기를 바꿔도 비율이 유지되고, 디버그 패널의 노브가 이 변수를
  직접 만진다

## 4. 배경 — 숨은 통합과학 개념 ★이 랜딩의 핵심

### 무엇이 숨어 있나
2022 개정 통합과학의 **6개 대단원**. 화면 전체에 흩어져 있다.

| 순 | 대단원 | 과목 |
|---|---|---|
| 1 | 과학의 기초 | 통합과학1 |
| 2 | 물질과 규칙성 | 통합과학1 |
| 3 | 시스템과 상호작용 | 통합과학1 |
| 4 | 변화와 다양성 | 통합과학2 |
| 5 | 환경과 에너지 | 통합과학2 |
| 6 | 과학과 미래 사회 | 통합과학2 |

**확정됨** (2026-07-28, 사용자 확인). 명칭·순서·통합과학1/2 배분 모두 이대로 간다.

### 숨길 에셋 10종 — 확정 (2026-07-28)

**대단원 1:1 대응을 강제하지 않았다.** 34종을 전부 누끼 떠서 검정 배경에 올려보고
고른 뒤, 사용자가 최종 10종을 지명했다. 소스는 전부 `motifs_accent` 계열이다 —
같은 개념의 base 버전은 검정에서 흐릿한 유리 덩어리가 되는데 accent 는 형태가
또렷하고 색이 남는다.

`atom` `dna` `chromosome` `mitochondria` `chloroplast` `synapse` `population`
`element` `tectonics` `universe`

순서는 `data.js` 의 `UNITS` 가 기준이고, `field.js` 의 `LAYOUT`·`TONE` 이 이 순서에
1:1로 묶인다. **하나를 끼워 넣으면 세 곳을 같이 고쳐야 한다.**

#### 톤을 에셋마다 다르게 잡는 이유
에셋의 원래 밝기가 제각각이라(중간휘도 134~215) 같은 opacity 를 주면 어떤 것은
헤드라인보다 밝아진다. 그게 "촌스러움"의 최대 원인이었다 — 마스크 모양이 아니라
**위계**의 문제다. 그래서 에셋별 `brightness()` 계수로 피크 렌더휘도를 전부 ≈68 에
맞춘다. 헤드라인 1행이 110 이므로 배경이 절대 앞서지 않는다.

#### 팔레트도 여기서 나온다 — 로열 H224 **확정**
전체 평균을 쓰면 유리 하이라이트에 끌려 흰색으로 씻겨나간다. 각 에셋의 **채도 높고
어두운** 픽셀(원자 링 음영·시냅스 소포 코어·은하 외곽)만 뽑으면 청색계 셋
(`atom` `synapse` `universe`)이 **H236** 으로 모인다. 거기서 조금 더 차갑게 민
**H224 '로열' 로 확정**했다(2026-07-28) — 보라 기운이 덜해 과학에 가깝고 검정 위에서
더 또렷하다.

```
--dim #5E6B9C   --accent #6B87DE   --glow #9EAEE1
--chip #101729  --t1 #606DA4       --t2 #EEF1FA
--line rgba(107,135,222,.26)
```

**로열은 버튼 하나에만 쓴다.** nav 메뉴는 흰색이다(사용자 지시) — 색이 곧 "누를 것"의
표시가 되게 하려는 것이고, 링크까지 같은 색이면 버튼이 안 튄다.
워시(빛)의 rgb 도 `--glow` 에서 파생시킨다. 캔버스에 rgb 를 적어 두면 팔레트를 바꿔도
빛만 옛 색으로 남는다.

#### 대단원 대응 (참고)
10종 중 `chromosome` `synapse` `mitochondria` 는 생명과학I 개념이고 통합과학
내용 요소에 없다(성취기준 원문 대조: `local/landing-refs/04-모티프-대단원-매핑.md`).
**사용자가 시각적 이유로 명시 지명했으므로 그대로 간다** — 랜딩 배경은 커리큘럼
표가 아니라 분위기이고, 화면에 개념명이 적히지 않으므로 오독 위험이 없다.

### 배치는 손으로 잡지 않는다

`pack-layout.py` 가 계산한다. 균등 난수로 뿌리면 무작위인데도 평평하고 투박하게
읽히므로 세 가지를 넣었다.

| 항목 | 값 | 이유 |
|---|---|---|
| 충돌 판정 | 회전 후 **잉크 마스크** | 경계상자로 하면 DNA 처럼 성긴 그림에서 77% 를 버린다 |
| 크기 | 10~25vw (데스크탑) | 난수가 아니라 **사다리(RAMP)를 섞는다** — 큰 것·작은 것의 공존을 보장 |
| 기울기 | ±34° (최소 7°) | 정립이 하나라도 있으면 스티커로 읽힌다 |
| 갭 | 16px | 사용자 지시로 34 → 16 축소 |
| 가장자리 | 30px | 런타임 부유(시차 8px + 자율 6px)를 미리 뺀 값. 10px 이면 잘린다 |
| 금지구역 | nav · 가장자리 · **강사와 그 오른쪽 전부** | 헤드라인 뒤는 허용(톤 위계가 잡혀 있으므로) |

강사 금지로 데스크탑 가용 면적이 **43%** 뿐이고 전부 좌측 절반에 몰린다. 크기가
더 안 커지는 이유가 이것이다 — 제약을 하나 더 걸 때마다 최대 크기가 내려간다.

### 어떻게 동작하나

**화면이 빛을 받고, 천천히 어두워진다.**

원판을 커서에 못 박아 두는 방식은 버렸다. 아무리 부드럽게 해도 원이었다
(사용자 판정 2026-07-28: "이게 찐 손전등이 아니라... 진짜 원이 아니라").

대신 **빛 밭(light field)** 하나를 둔다. 화면을 12px 격자로 덮은 스칼라 장이고,
매 프레임 세 가지가 일어난다.

| | |
|---|---|
| 감쇠 | 전체가 조금씩 어두워진다 `F *= exp(-0.40·dt)` — 3초 뒤 30%, 6초 뒤 9% |
| 바르기 | 커서 자리에 빛을 더한다. 완벽한 원 하나가 아니라 **느리게 도는 어긋난 덩어리 셋** |
| 번짐 | 빛이 옆으로 스며든다 `D=4 셀²/s`. 덩어리의 기하학이 뭉개진다 |

그래서 밝은 모양은 원이 아니라 **커서가 지나간 길**이다. 빠르게 그으면 길게 번지고,
천천히 움직이면 뭉치고, 멈추면 그 자리가 포화돼 계속 밝다.

**머물면 자리가 커진다.** 한자리에 오래 있을수록 붓이 최대 3배까지 자란다(5초 만재).
실측 반치반경 150 → 270px. 번짐만으로는 4초에 28% 밖에 안 자랐다 — 확산은 퍼지면서
동시에 묽어져 가장자리가 문턱을 못 넘기 때문이다. 붓 자체를 키우는 쪽이 눈에 보인다.
빠져나갈 때는 2.5배 빠르게 줄어든다 — 안 그러면 긋는 선이 점점 굵어진다.

#### 밭 하나가 세 가지를 다 몰아준다
장치가 셋이면 화면에서도 셋으로 읽힌다. 그래서 같은 밭을 세 군데가 나눠 쓴다.

- **광량** — 밭을 그대로 옅게(0.13) 깐다. "화면이 빛을 받았다"가 이것이다
- **모티프** — 밭에 감마 1.7을 먹여 마스크로 쓴다. 문턱이 높아 아주 밝은 데서만
  드러나므로 한 개가 통째로 뜨지 않고 **조금씩** 보인다.
  실측: 커서 자리 알파 75 · 같은 모티프 105px 옆 0 · 다른 모티프 0
- **먼지** — 밭의 **기울기**를 밀어내는 방향으로 쓴다. 방사 대칭이 아니라 빛이 번진
  모양을 따라 걷히므로 여기서도 원이 나오지 않는다

#### 구현 메모
- 밭은 **JS Float32Array** 로 돌린다. 캔버스에 두고 `getImageData` 로 읽으면 매 프레임
  GPU→CPU 회수가 끼어들어 프레임이 튄다. 화면에 올릴 때만 작은 ImageData 로 옮긴다
- 모티프는 DOM 요소가 아니라 캔버스다. `opacity` 는 요소 전체에 걸리므로 "원자의 왼쪽
  고리만 보인다" 를 표현할 방법이 없다 — 반응 단위가 픽셀이어야 했다
- 모티프 원판(ink)은 자리가 고정이라 **한 번만 굽는다**. 톤도 canvas filter 로 미리
  태워 프레임 비용을 0 으로 만든다. 이미지는 **다 받은 뒤에** 굽는다 — 반쯤 받은
  상태로 구우면 빈 캔버스가 남고 다시 구울 계기가 영영 오지 않는다
- 명시적 확산은 `D·dt ≤ 0.25` 를 넘으면 발산한다. 한 프레임에 쓸 양을 0.24 로 잘라
  탭 복귀 직후처럼 dt 가 튀는 프레임에서 화면이 하얗게 타는 것을 막는다
- 전면 합성 추가비용 실측 **0.01ms/프레임** — 이 구조는 성능이 문제가 아니다

#### 포인터 판정은 이벤트로만 한다
마운트 시점 `matchMedia('(hover:hover) and (pointer:fine)')` 를 믿으면 안 된다 —
터치 노트북과 헤드리스에서 참이라, 영영 오지 않을 `pointermove` 를 기다리며 히어로가
검게 남는다. 기본값은 "포인터 없음"(자율 배회가 대신 바른다)이고, `pointerType` 이
touch 가 아닌 `pointermove` 가 실제로 한 번 들어온 뒤에야 붓이 커서 소유로 넘어간다.
`prefers-reduced-motion` 은 자율 위치에 빛을 충분히 발라 한 프레임으로 구도를 만든다.

#### 디버그 모드 — ⌘⌥D
`debug.js` 는 **단축키를 누르기 전까지 내려받지도 않는다**(동적 import). 실사용자에게는
없는 파일과 같다. `field.js` 가 노출하는 `window.__field` 훅만이 유일한 접점이고,
읽는 쪽이 없으면 아무 일도 하지 않는다.

노브는 **전부** 여기 있다 — 블루 6종, 강사 크기·위치, 먼지 7종(개수·크기·밝기·
반짝임·부유), 바람 7종(창 반경·밀어냄·쓸림·소용돌이·옅어짐·밀림/되메움 속도),
모티프 2종, 헤드라인 줄 간격. 별도 페이지(`tune.html`)로 두었던 것을 접었다 — 실물 위에서 봐야
값이 맞는지 알 수 있다.

- 손잡이를 끌어 아무 데나 놓는다. 가장자리 24px 안이면 달라붙는다
- **헤더를 클릭하면 한 줄로 접힌다**(188×29). 접혀도 `asset·80svh·58%` 처럼
  현재 값을 말해 준다. 끌기와 접기를 같은 헤더에 태웠고, 3px 이상 움직였는지로
  구분한다
- 위치·접힘·모든 값이 localStorage 에 남는다. 키에 버전을 붙여(`-v3`) 코드
  기본값이 바뀌면 옛 저장값이 자동으로 버려진다
- **"초기값으로"** — 저장값을 지우고, `:root` 인라인 변수를 `removeProperty` 로
  걷어내고(값만 되돌리면 인라인이 스타일시트를 계속 이겨 CSS 를 고쳐도 화면이
  안 바뀌는 유령이 남는다), CFG 를 코드값으로 되돌린다.
  기준값은 **처음 열 때 한 번만** 뜬다 — 매번 뜨면 그때의 조정값이 "초기값"이 된다
- 패널을 여는 것만으로는 화면이 바뀌지 않는다. 저장값이 없으면 코드값을 그대로
  물려받는다

> 강사를 옮기면 **모티프 금지선이 같이 움직인다.** 패널 하단에 `pack-layout.py`
> 상수와 경계 %가 뜨므로 그대로 넣고 다시 돌리면 된다.

#### 포인터 판정은 이벤트로만 한다
마운트 시점 `matchMedia('(hover:hover) and (pointer:fine)')` 를 믿으면 안 된다 —
터치 노트북과 헤드리스에서 참이라, 영영 오지 않을 `pointermove` 를 기다리며 히어로가
검게 남는다. 기본값은 "포인터 없음"(자율 배회로 보인다)이고, `pointerType` 이
touch 가 아닌 `pointermove` 가 실제로 한 번 들어온 뒤에야 빛이 커서 소유로 넘어간다.
`prefers-reduced-motion` 도 같은 경로를 타 정적 1프레임으로 구도가 완성돼 보인다.

### 왜 이 방식인가
- 어둠 속에 전부 있고, 건드려야 드러난다 = **"철두철미"의 시각화**. 빠뜨린 게 없다는 주장을 말이 아니라 화면으로 한다
- 조사 결론(`README.md` §3)의 빈자리를 정확히 친다 — 38명 중 아무도 "무엇을 어떻게 다루는지"를 히어로에서 보여주지 않는다
- 방문자가 **직접 만져서 발견**하므로 체류시간과 관여도가 올라간다

### 7-1. 커리큘럼

**이 섹션의 임무는 판매가 아니다.** "생명과학 1타가 통합과학을 하나"라는 의심에 대한
답이다. 통합과학은 물·화·생·지 전 영역이라 그게 첫 질문이 된다. 그래서 강좌 목록이
아니라 **6대단원 전 영역 커버리지 증명**이고, 히어로("어둠 속에 전부 있다")와 같은
주장을 두 번째로 하는 구조다.

#### 축 — 시기축을 쓰지 않는다
2028 첫 사이클이라 월별 배치를 확정할 수 없고 갱신 부담이 크다. 조사에서 진도표를
메뉴로 만들어 놓고 못 채운 곳이 둘이었다(김현정 "내용 준비중", 준과학 404).
또 **LMS의 주차 커리큘럼과 분리해야 한다** — `backend/apps/curriculum/`의
`released()`는 PRD §4에 따라 "시작된 주차까지만" 공개하고 목적이 경쟁사 차단이다.
비로그인 랜딩에 주차 진도를 그리면 그 원칙을 정면으로 깬다.

→ **갱신 부담이 0인 고정축 2개만**: 6대단원(교육과정이 정함) × 4단계(업계 표준어).

> **강좌 라인업은 새로 만들지 않는다**(2026-07-28 확정). 지금 있는 것 —
> 철두철미 시리즈(개념완성/실전모의고사/완자), 로직N제, 자분기, 만점시퀀스, M.D.G.C —
> 을 아래 4단계 × 2트랙 축에 **재배치**한다. "철두철미"는 사용 가능하다(A-2 해소).

#### 구성
```
커리큘럼                                        최종 갱신 26.07.28
2028 수능, 과학은 통합과학 하나다.        ← 리드 (카피 확정 필요)

  [ 고1·고2 내신 통합과학 ]  [ 2028 수능 통합과학 ]   ← 목적 2트랙

  입문 → 개념완성 → 문제풀이 → 직전대비              ← 4단계 (세로 계단)
  ┌────────────────────────────────┐
  │ 개념완성                 [필수] │  단계 라벨 + 배지
  │ 철두철미 완자 통합과학          │  강좌·교재명
  │ 물화생지 전 영역 개념의 완결     │  한 줄, 명사 종결
  │ ● 물질과 규칙성 ● 시스템과 상호작용│  대단원 칩 ← 우리만의 축
  └────────────────────────────────┘

  ─ 실전 모의고사 ─                                ← 단계 축 밖 별도 밴드

  6대단원 × 4단계 커버리지 매트릭스                  ← 6행이 다 차는 그림 = 증명
```

**따르는 것** (어휘·정보 구조는 인지 비용이라 표준을 쓴다)
- 이름은 `커리큘럼`. 로드맵·진도표·학습플랜 안 씀
- 단계 어휘는 업계 표준어. 새 조어 만들지 않음
- 카드는 **4요소로 절제**: 단계 라벨 + 강좌/교재명 + 한 줄 + 배지
- **가격·강의수·수강기간 안 넣는다** — 커리큘럼 층의 업계 불문율(예외 0건)
- 실전 모의고사는 단계 축 밖 별도 밴드 (메가 강사 4명 전원의 처리)

**깨는 것**
- **이미지·영상 커리큘럼을 만들지 않는다.** DOM 텍스트 단일 소스 하나만 →
  표/포스터 불일치와 방치를 구조적으로 차단
- **모달·팝업이 아니라 스크롤 섹션** (조사 대상 전무)
- **커리큘럼에도 `최종 갱신` 날짜를 박는다** — 정오표에서만 쓰이던 관리 신호를
  확장하면 두 섹션이 하나의 주장으로 묶인다 (업계 전무)
- **6대단원 축 도입** — 업계는 단계×과목 2축뿐, 교육과정 단원을 올린 곳이 없다

**전환기 신호**: 통합과학은 2028이 첫 시행이라 **수능 기출이 없다.** 그래서 업계 표준
6단계 중 `기출분석`을 뺀다. 이걸 화면에서 한 줄로 말하는 것 자체가 전문성 신호다.
(다만 "기출이 없다"가 불안을 자극할 수 있어 톤 판단 필요)

**하단 고지** (EBS 어법을 빌린다):
> 본 커리큘럼은 2028학년도 대비 기준이며, 교육과정·출제 방향 확정에 따라 일부 변경될 수 있습니다.

### 7-2. 교재 정오표

**첫 통합과학 교재부터 정오표를 세워두는 것 자체가 포지션이다.**
대성마이맥 통합과학 강사 5명 중 정오표 운영자는 1명뿐이고, 시대인재북스는 과탐 교재에
"정오표 확인 방법.pdf"를 정오표라고 내려준다.

#### 구성
```
교재 정오표
교재에서 확인된 오류는 전부 여기 올립니다.
최근 갱신 26.07.28 · 교재 4종 · 정정 12건        ← 3초에 "살아있음" 판정

교재명                          대상      정정   최초 게시   최종 수정
철두철미 완자 통합과학2 [NEW]   고1 내신   5건   26.03.11   26.07.28
철두철미 완자 통합과학1         고1 내신   4건   26.03.11   26.06.24
        ↓ 행 클릭 → 인라인 확장 (★업계 유일)
위치       페이지  수정 전        수정 후       반영
3단원 2강   142    …감소한다     …증가한다    26.07.28
                                       [엑셀 내려받기]

여기 없는 오류를 발견하셨나요?                    [ 제보하기 ]
```

**따르는 것**
- 이름은 **`교재 정오표`** (전수 14/14 표준). 윤도영식 `정오사항`은 개인 표기라 안 따름
- 항목명은 `{교재명} 정오표` — 교재명이 앞
- **제보 채널을 반드시 붙인다** — 정오표는 업계에서 혼자 서지 않는다
- 화면 날짜 `YY.MM.DD`, 표 스키마는 업계가 파일 안에서 합의한 5열 그대로

**깨는 것**
- **파일이 아니라 웹 표가 기본.** 다운로드는 보조 버튼
- **`최종 수정일`을 1급 데이터로 두고 정렬 기준으로** — 업계는 제목에 수기로 박는다
- **로그인 벽 없음** (메가·이투스는 로그인 필수 → "관리한다"는 메시지를 스스로 깎는다)
- **스크린샷 금지** — 윤도영은 5개 중 4개가 PNG라 검색·복붙·접근성이 0
- **"더보기로 N개만" 금지** — 윤도영은 이 컷 때문에 최근 갱신 2건이 정확히 숨었다

#### 운영 부담 설계 ★
업계 실패는 전부 여기서 나왔다 — 제목에 날짜 수기 입력 → 박제(윤도영 파일 안에
`최근 반영일: 2023.04.18`과 실제 `2026.06.24`가 나란히 보인다), 파일명 규칙 혼재
(지학사는 한 사이트에 5가지 포맷), 정렬 붕괴. **사람이 하는 일을 줄이는 게 설계 목표다.**

- **운영 주체 확정**(2026-07-28): **우리가 직접 올린다.** 강사·조교에게 넘기지 않는다.
  → 업계 실패 사례(담당자 부재로 섹션이 죽는 것)의 주원인이 제거됐다.
  다만 입력이 편해야 지속되므로 아래 붙여넣기 입력 설계는 그대로 간다
- **입력 창구는 하나. 새 CMS를 만들지 않는다.** LMS에 이미 있다 —
  `backend/apps/boards/models.py`의 `Post.Category.ERRATA`(코드 확인 완료).
  랜딩은 이 데이터를 공개 API로 읽어 렌더한다
- **다만 현재 `Post`는 `title`/`body`뿐이라 웹 표를 못 그린다**(확인 완료).
  `errata_items` 자식 테이블 신설 + **"엑셀에서 복사 → 붙여넣기 → 행 파싱"** 입력 권장.
  xlsx 다운로드는 저장된 행으로 **서버가 생성** → 사람이 파일명을 안 짠다
- **날짜는 사람이 입력하지 않는다.** `created_at`/`updated_at` 자동 기록을 2열로 그대로.
  ⚠️ 현재 `Post.updated_at`은 `auto_now` 없는 nullable(확인 완료)이라,
  정오 항목만 고치고 부모 글 `updated_at`을 안 올리면 **정렬이 그대로 무너진다**
- **빈 기간을 미리 설계한다.** 정오표는 교재 출시 직후에 몰리고 그 뒤 산발적이다.
  빈 섹션을 숨기지 말고 빈 상태로 보여준다 — 숨기면 "없는 것"과 "안 하는 것"이 구분되지 않는다
- 수식·도표 정정은 이미지가 불가피하니 허용하되 **텍스트 설명 + 대체텍스트 필수**로 강제

---

### 7-3. 컨택트

**채널톡 임베드.** 별도 폼을 만들지 않는다.
정오표의 `[제보하기]`도 채널톡 프리필로 연결 → 정오표 옆에 제보 채널을 두는 업계 관행을
채널톡 하나로 충족하면서 컨택트 섹션과 동선이 닫힌다.
