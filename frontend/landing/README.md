### 모티프 — 통합과학 3축 대응
- `atom` — 통합과학1 '물질과 규칙성'. 전자껍질 궤도 모형은 현대 오비탈 이론상 구식이지만 **교육과정이 실제로 가르치는 모델**이라 이 맥락에선 정확하다
- `dna`, `dna-2` — '시스템과 상호작용: 생명 시스템'. `dna-2`가 B형 구조(우선회·주홈/부홈·사다리형 염기쌍)를 명시해 염기쌍이 더 또렷하다
- `earth-system` — '시스템과 상호작용: 지구 시스템'. 지권·수권·기권·생물권 4권역이 맞물린 형태

> 기존 모티프 32종을 감수한 결과 **과학적으로 식별 가능한 것은 8종뿐**이었고 세트 전체가 생명과학I에 편중돼 있었다. `local/assets/motifs/`에 2K 마스터와 생성 스크립트가 있다(gitignore).

### 강사 사진 — 손이 간 이유
원본은 캐러셀 스크린샷이라 **좌우 화살표와 하단 점 인디케이터가 박혀 있었다.** 화살표는 배경 제거 시 함께 사라지지만, 점은 인물 실루엣에 닿아 있어 연결성분 필터로도 안 걸러진다. 하단 10%를 잘라 제거했다(가슴~허벅지 구도라 손실 없음).

누끼 도구: rembg `isnet-general-use`. 인물에는 알파 매팅 없이 쓰는 게 낫다 — 매팅을 켜면 이 크기에서 6분 넘게 걸린다.

## 3. 랜딩 방향 (PRD §3.3.3, 6-10)

**목적**: 잠재고객 → **상담·문의 요청** 전환. 단일 CTA.
**독자**: 학생이 보고 학부모가 신청한다.

### 조사로 나온 포지션
경쟁사 16곳·과학강사 38명을 훑은 결론:

> **관리를 말하는 곳은 디자인이 낡았고, 디자인이 좋은 곳은 관리를 말하지 않는다.**

- 윤도영("어차피 결국은 윤도영")·시대인재("Hidden Score", "만점구조시스템") — 세련됐지만 내용이 공허
- 김현정·짱솔 — "의무 보강", "누적테스트"처럼 관리는 구체적이나 구형 템플릿
- **자체 사이트를 가진 과학강사는 38명 중 윤도영 하나뿐**
- **통합과학 전담은 장풍 하나**, 나머지는 전부 기존 과목 겸업 → 2028 전환기에 자리가 비어 있다
- CTA는 규모로 갈린다 — 대형은 "문자 수신 DB 등록", **개인 브랜드는 "1:1 상담신청"**

### 쓸 수 있는 본인 자산
지어낼 필요 없이 메가스터디에서 이미 쓰는 것들:
- **"통합과학도 철두철미하게"** — 이름의 '철'과 교재 브랜드(철두철미 개념완성·실전모의고사·완자)가 한 줄로 꿰인다
- **"콕스(cox)"** — 조정 키잡이. 소개 영상 제목이 "여러분의 콕스 한종철쌤이 레이스를 함께 합니다". 학생이 젓되 방향은 내가 잡는다 = PRD가 말하는 "차별화된 관리"
- "개념, 스킬, 논리 그리고 속도감" / "러셀 생명과학 1위"

## 4. 다시 만들 때 알아야 할 것

### 배경 문제는 풀 게 아니라 없애는 것
스크롤 스크러빙(Apple식 프레임 시퀀스)을 하면 "모티프를 투명하게 유지하면서 어떻게 배경과 합성하나"가 문제로 보이는데, **참고한 유튜브 방식은 이걸 푼 게 아니라 없앴다** — 영상 자체가 히어로 배경이고 텍스트·사진은 그 위에 얹는다(프레임도 알파 없는 JPG로 뽑는다). 그러면 "배경이 좌우를 관통한다"가 자동 충족되고, 프레임별 알파 추출에서 오는 깜빡임 리스크도 사라진다. 누끼는 강사 사진에만 필요하다.

### 생성 프롬프트 3규칙 (전부 실제로 밟은 지뢰)
| 실패 | 원인 | 규칙 |
|---|---|---|
| 화면에 진짜 지퍼가 등장 | `like a zipper` | **비유 금지 — 비유는 오브젝트가 된다** |
| 완전한 이중나선이 2개 생성됨 | `DNA` `helix` + 분리 지시 → 모델이 복제까지 완성 | **도메인 명사 금지** |
| 동작이 목표를 지나침 | 끝 상태 미지정 | `last_frame` 필수 |

→ 순수 물리·기하 서술만: `twisted pair of ribbons`, `short bars bridging between them`, `break at their midpoint`, `glide apart`

**그리고 `last_frame`으로도 중간은 통제 못 한다.** 양 끝을 이미지로 못 박아도 중간 프레임에서 사고가 난다(지퍼가 거기서 나왔다). 영상이면 스쳐 갈 프레임이 **스크러빙에서는 사용자가 손을 멈춘 정지 화면**이 되므로, Veo에 "형태가 바뀌는 구간"을 맡기지 말고 CSS/DOM으로 빼는 편이 안전하다.

### 성능 상한은 파일 용량이 아니라 디코드 메모리
1600px 프레임 96장은 파일로 약 3MB(장당 30KB)지만 **디코드 RGBA는 장당 약 3MB**라 전량 상주하면 300MB에 육박한다. 아이패드(PRD §4 — 학생·학부모 1순위 기기)에서 탭이 죽는다. 슬라이딩 윈도로 현재 프레임 주변만 들고 있어야 하고, 참고 영상이 쓴 240프레임은 우리에겐 과하다.

### 파이프라인은 전부 API로 된다
Antigravity·Whisk·Flow·ezgif 같은 외부 툴이 필요 없다 — Gemini 이미지(`gemini-3-pro-image`) → Veo 3.1(`image` + `last_frame` 보간, 8초/1080p, 클립당 약 80초) → ffmpeg 프레임 추출. 1:1 소스는 16:9로 미리 확장해야 레터박스가 안 생기고, `generate_audio`는 Gemini API 미지원이다.

> ⚠️ 2026-07-22 기준 Gemini 이미지 API가 **프로젝트 월 지출 한도 초과**로 막혀 있다. 대기로는 안 풀리고 https://ai.studio/spend 에서 한도를 올려야 한다.
