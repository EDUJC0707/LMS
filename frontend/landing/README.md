# 랜딩 페이지 — 작업 기준 문서

한종철 통합과학 비로그인 랜딩. 2026-07-22 기준.
LMS 본체(`frontend/src`)와 분리된 **실험 단계**라 이 폴더 안에서만 작업한다.

---

## 1. 목적

**잠재고객 → 상담·문의 요청 전환** (PRD §3.3.3, 6-10)

- 타깃: 수업 선택을 고민 중이거나 설명회 듣고 검색해 유입된 사람
- 독자 구조: **학생이 보고 학부모가 신청한다** (두 화자를 한 페이지에서 처리)
- 전환 종착점은 **상담·문의 요청 단일 CTA** — 수강신청·설명회·문자DB 아님

## 2. 왜 이렇게 만드는가 (조사 근거)

경쟁사 16곳·과학강사 38명 조사 결론:

> **관리를 말하는 곳은 디자인이 낡았고, 디자인이 좋은 곳은 관리를 말하지 않는다.**

- 김현정·짱솔·준과학은 "의무 보강", "누적테스트" 같은 관리를 구체적으로 서술하지만 구형 템플릿
- 윤도영("어차피 결국은 윤도영")·시대인재("Hidden Score", "만점구조시스템")는 세련됐지만 내용이 공허
- **자체 사이트를 가진 과학강사는 38명 중 윤도영 하나뿐.** 한종철이 두 번째가 되는 것 자체가 포지션
- CTA는 규모로 갈린다 — 대형은 "문자 수신 DB 등록", **개인 브랜드는 "1:1 상담신청"** → 우리 선택이 개인 브랜드 표준과 일치

한종철이 이미 가진 언어 자산: **콕스(cox, 조정 키잡이)**, **철두철미**(이름의 '철'과 연결된 중의법), "개념·스킬·논리 그리고 속도감", "러셀 생명과학 1위"

## 3. 구조

전체 **약 2페이지** 분량. 윤도영처럼 단순하되 훨씬 세련되게.

```
┌────────────────────────────────────────────┐
│  히어로 — 영상이 전체를 덮는 배경 (풀블리드)    │
│                                             │
│   DNA (화면 왼쪽)      한종철 사진 (누끼)      │
│                       태그라인               │
│                       [상담 신청]            │
└────────────────────────────────────────────┘
              ↓
   아래는 윤도영식 단순 섹션 (더 세련되게)
```

- 배경 하나가 좌우를 관통해 **그래픽과 사진이 두 개의 박스가 아니라 하나의 장면**이어야 한다
- 태그라인은 우리가 작성

## 4. 히어로 연출

**DNA 이중나선 회전 → 열리면서 회전이 멎음 → 두 가닥이 양옆으로 → 스크롤하면 그 사이로 진입**

구조 정확도 (사용자 제공 RNA/DNA 도해 기준):
- DNA = 당-인산 리본 **2개** + 그 사이를 잇는 **염기쌍(bars)**
- "중간이 열린다" = 가운데를 가로지르는 **염기쌍이 중간에서 끊어진다**
- 갈라진 각 가닥 = 리본 1개 + 안쪽으로 삐져나온 반쪽 염기 (RNA 그림과 형태는 같으나 **RNA 아님, DNA 단일가닥**)

타이밍: **열리면서 회전이 멎는다**(동시). 그 다음 두 가닥이 양옆으로.

## 5. ★ 배경 문제 — 해법

가장 오래 헤맨 지점. 결론부터:

> **유튭 방식은 배경 문제를 푼 게 아니라 없앴다. 영상이 곧 히어로 배경이다.**

자막 원문 근거:
- *"Please add this video to the background of our hero section. Do not add any overlay over the video."*
- *"build me a hero section on a pure black background. Position the text and the content same as on the reference images"*
- 영상 2번은 프레임을 **JPG**로 추출 — JPG는 알파 채널이 없다

따라서:
- 영상은 **떠다니는 투명 오브젝트가 아니라 화면 전체를 덮는 배경**이다
- 텍스트·사진·CTA는 그 위에 레이어로 얹는다
- **"배경이 좌우를 관통한다"가 자동 충족** — 영상 하나가 전체 배경이므로
- **프레임 알파 추출 불필요** → 프레임마다 매트가 흔들려 깜빡이는 리스크 소멸
- 누끼는 **강사 사진만** 따면 된다 (인물은 rembg가 안정적)

## 6. 프롬프트 규칙 (실패에서 얻은 것)

| 실패 | 원인 | 규칙 |
|---|---|---|
| 완전한 이중나선 2개가 나옴 | `DNA` `helix` + `separate` → 모델이 복제까지 완성 | **도메인 명사 금지** |
| 화면에 진짜 지퍼가 등장 | `like a zipper` | **비유(simile) 금지 — 비유는 오브젝트가 된다** |
| 동작이 목표를 지나침 | 끝 상태 미지정 | **`last_frame` 필수** |

→ 순수 물리·기하 서술만: `twisted pair of ribbons`, `short bars bridging between them`, `break at their midpoint`, `glide apart`

## 7. 파이프라인 (전부 API — 외부 툴 불필요)

| 유튭 | 우리 | 상태 |
|---|---|---|
| Whisk (이미지) | `gemini-3-pro-image` | ✅ |
| Flow (frames-to-video) | **Veo 3.1** `image` + `last_frame` | ✅ 실측: 1080p 16:9, 클립당 75~80초 |
| ezgif (프레임 추출) | ffmpeg | ✅ |
| Antigravity (빌드) | 여기서 직접 | ✅ 불필요 |

주의: `generate_audio`는 Gemini API 미지원. 1:1 소스는 16:9로 미리 확장해야 레터박스가 안 생김.

## 8. 시안 5개

히어로 연출을 **5개 뽑아 고른다.** 톤(다크/라이트)은 asset마다 결정.

| | 톤 | 그래픽 | 사진 | 노리는 것 |
|---|---|---|---|---|
| A | 다크 | DNA 분리·진입 | 검정수트 | 시대인재급 권위. 유리가 가장 빛남 |
| B | 라이트 | DNA 분리·진입 | 흰니트 | 윤도영·The CONTACT 계열. 정갈·신뢰 |
| C | 다크 | 원자→분자→세포 스케일 | 검정티 | "왜 통합과학인가"를 그림으로 |
| D | 라이트 | 지구 4권역 분해 | 흰니트 | 영상 2번 분해도 방식 그대로 |
| E | 좌 다크 → 우 라이트 | DNA 분리·진입 | 검정티 | "배경이 좌우를 관통"을 문자 그대로 |
