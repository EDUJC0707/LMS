1. 영상 호스팅 결정 필요

요건

  • 다운로드 불가
  • 콘솔로 링크를 찾아도 재생 불가 (= DRM 필수)
  • 워터마크 (가점)
  • 4K 원본 · LMS(웹·앱) 임베드

DRM · 영상 자체를 암호화하는 기술입니다. 학생이 개발자도구로 영상 주소를 빼내도 파일이 암호화돼 있어 재생되지 않습니다. 복호화 열쇠는 "로그인한 그 학생·그 기기"에만 잠깐 발급됩니다.

RPA · 사람이 하던 반복 클릭을 봇이 대신하는 자동화입니다. 여기서는 유튜브에서 학생 계정에 영상 권한을 부여/회수하는 작업을 봇이 자동 처리합니다.

2. 문의·상담·전화 결정 필요

채널톡 도입 여부. 채널톡은 카카오톡·인스타 DM·전화·웹 문의를 한 화면에서 처리하는 상담 서비스입니다.

도입하면 (추천)

  • 학부모·학생 문의가 어디로 오든(카톡·인스타·웹) 한 곳에서 응대
  • 결석생 상담 전화가 자동 녹음·AI 요약되어 LMS의 학생 기록에 자동으로 남음 — 핵심 이점
  • 결석생 상담 명단 자동 추출, 학생별 통화 횟수 표시 등 LMS와 연동
  • 비용 · 대략 월 5~6만원 (플랜 27,000원 + 전화번호 5,000원/월 + 통화료 무선 72원/분)

도입 안 하면

  • 이 기능들을 직접 개발해야 함 — 그런데 전화 녹음·음성→텍스트·AI 요약·카톡/인스타 통합은 자체 개발이 사실상 어렵고 부담이 큼

3. 클리닉 화상 확정 제안

구글 미트. 신청 → 미트 링크 자동 생성 → 진행(녹화·전사·AI요약 ON) → 구글 드라이브 자동 저장 → LMS 기록

  • 드라이브 저장·API 연동 확인됨 · 녹화·전사·AI요약이 드라이브에 저장되고, LMS가 API로 전사·출결(입·퇴장 시각)·AI요약을 수집
  • 전사·AI요약 한국어 지원 · 학생은 무료 참여 · 신청·취소·캘린더는 LMS 자체 개발
  • 비용 · 호스트(조교) 계정당 $14/월(약 2만원) × 동시 진행 조교 수

4. 알림톡 확정 제안

솔라피. 성적 등록·학부모 리포트·영상 지급·클리닉·결석 등 서버 이벤트를 카카오 알림톡으로 자동 발송.

  • 건당 약 13원 (물량 늘면 더 저렴)
  • 학생 300명 기준, 주당 약 2,000건 넉넉히 예상 → 주 약 3만원 · 월 약 10~12만원
